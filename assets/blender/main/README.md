# 主岛模型交付

依据用户提供的「主岛 · 建模参考（2–12）」制作，采用可编辑的低多边形几何和纯色材质。共 11 类参考物件，另增加独立椰树。是面向网站的简化模型，不是参考图逐像素复刻。

## 文件

- `../main_island_library.blend`：完整模型库，每种资产一个 Main_ 场景；默认显示主岛小屋。
- 本目录各 `.blend`：独立模型，已重新打开检查并保存可用查看视角。
- `previews/`：每个资产正面与背面渲染。
- `contact_sheet.jpg` / `contact_sheet_rear.jpg`：总览，各卡片独立取景，非同比例。
- `../../../public/models/main/manifest.json`：完整清单、尺寸、部件与模块路径。
- `../../../public/models/main/`：12 个完整 GLB，modules/ 内 38 个独立模块。

## 网站接入

Blender Z 向上、-Y 为前方，GLB Y 向上、+Z 为前方。普通模型底部为地面 0；船以水线为 0，码头以甲板为 0（桩向下延伸）。鱼群为展示集合，运行时建议使用单鱼模块。

可动部件通过 extras.part_id 定位：front_door、lid、mainsail、jib、rudder、light_rotor。当前仅保留转轴节点，没有预烘焙动画。网站主岛已使用这些 GLB 替换旧模型，并按实际摆放调整碰撞、窗户发光、灯塔光束、船只航线和鱼群游动。椰树独立摆放以避免穿墙。主岛横向扩约 8%、前后扩约 20%，瓶体维持原尺寸。新增真实 GLB 加载、室内行走、码头碰撞、船只避岸及资源释放测试；113 项测试及生产构建通过。
