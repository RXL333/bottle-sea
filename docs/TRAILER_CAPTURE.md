# Trailer Capture Mode / 宣传片拍摄模式

仅在 Vite 开发环境启用。启动 `npm run dev`，在游戏地址后加 `?trailer=1`。
可以指定起始镜头，例如 `?trailer=1&shot=combine-harvest`。正式 build 不包含拍摄面板和镜头模块。

## 快速录制

1. 选择镜头，等待场景准备结束。
2. 调整画质、声音、是否显示玩家。默认为干净 HUD 和真实 9:16 摄影机。
3. 点击 **Reset Shot**，然后 **Play Shot**。
4. 按 **F8** 隐藏全部拍摄面板，使用录屏工具录制。F8 再次显示；Esc 也能显示面板。
5. 预设镜头重拍时 Reset 会恢复机位、时间、季节、天气、作物、车辆、粮仓、NPC 初始位置和动画相位。自定义轨迹的 Reset 只重置轨迹与环境，保留手动布景。

9:16 是实际摄影机比例，不只是安全区标记。横向窗口会有黑边，可在录屏软件中裁掉黑边；竖向窗口会尽量铺满。也可选择 16:9 或跟随窗口。选择横屏后 Reset 会重新构图，拉近瓶子、农机和牧场主体，并调整农场航拍高度。正常游戏的画幅不变。

## 十段横屏样片与本地导出

已录制的最终样片在 `artifacts/trailer-samples/Bottle-Sea-Landscape-1080p-20261007/`，旁边的同名 ZIP 包含所有视频及离线预览页。共十段独立 H.264 MP4、1920×1080、16:9、30fps、总时长 194 秒。视频无 HUD、无标题、无配乐、无声音，可直接导入剪辑软件。

新增“拍摄十个横屏 MP4”按钮：以固定时间步逐帧渲染游戏 Canvas，使用本地 FFmpeg 编码，不受实时游戏帧率波动影响。导出期间常规动画循环暂停；拍完恢复。可随时停止，已经完成的视频保留。输出写到新的独立批次目录，不覆盖原有视频。

使用该按钮前，将 FFmpeg 加入 PATH，或通过环境变量 `BOTTLE_SEA_FFMPEG` 指定可执行文件再启动开发服务。编码接口只在开发服务启用，只接受本机同源请求，图片尺寸、帧序和文件标识均有校验；与正式 SaveSystem 无关。该工具不录制实时音频。

交付视频已经逐段完整解码，验证 5820 帧、尺寸、帧率和编码正确；起中末画面及四季、天气阶段也已抽查。`validation.json` 包含每段文件的 SHA-256，`index.html` 可离线逐段播放。复验打包脚本：`scripts/package-trailer-samples.py`。

## 自由机位与轨迹

- **WASD**：前后左右；**Q / E**：降 / 升；**Shift**：加速。
- **方向键**：旋转；**鼠标左键拖动**：观察。无需锁定鼠标。
- 可调整移动速度、旋转速度、平滑响应、FOV。
- 自由摄影机摆好起点后点击“记录起点”，移到终点后点击“记录终点”，设置持续时间并“应用轨迹”，再 Play。
- 起终点轨迹采用平滑加减速和四元数旋转。编辑器可保留 2–16 个机位；多个点使用连续曲线。
- “生成缓慢环绕轨迹”围绕当前农机，或自由机位前方 8 米注视点旋转，可选择 30–360 度。
- JSON 轨迹可以复制保存到外部文本，再粘贴回来应用。当前面板设置和自定义轨迹不写入玩家存档。

## 临时场景与暂停

Home / Farm / Travel 使用已有世界切换接口。可以设置四季、四种天气、四个时间段或精确小时。
农场可准备成熟 / 生长 / 幼苗 / 刚播种作物，调整农机位置、NPC 位置和动物待机 / 行走 / 进食 / 睡眠表现。
农机摆位仍受已有地形、碰撞和有效区域约束。人物或农机 ID 必须属于当前世界。

**暂停世界**冻结环境动画、动物和农机运动，但摄影机仍可调整或播放轨迹。
**停止镜头**停止轨迹和演示农机，风雨、作物摇摆等正常动画继续。拍摄时全局游戏日期保持所选时间，动画仍使用 GameClock 的动画时间；天气延时镜头主动调整同一个 GameClock。
音频需点击“启用拍摄声音”获取浏览器手势许可，可以独立设置本次拍摄音量。

## 隔离方式

拍摄从新的默认状态开始，使用独立内存 Storage，既不读取也不写入正式 SaveSystem 的浏览器存储。
即便同时传入 `persist=1`，也不会触及正式存档。世界、背包、农田、车辆、粮仓、金币、NPC、里程碑、委托和图鉴均属于本次临时会话。
收割机镜头调用已有收割 API，产物只进入副本粮仓，不改变正式农田或库存。
动物动作和 NPC 摆位只改本次表现；牧场背景风车为现有模型的临时副本，不修改正式地图。
拖拉机预设会在临时中央田中准备已收割通道，防止低机位被麦穗遮挡；不发放任何收获物，也不改变正常农田。

使用“退出拍摄模式”回到无拍摄 / 预览参数的普通游戏，重新读取原来的正式存档。刷新拍摄页面则重新创建默认拍摄会话；临时改动不会持久化。

- TypeScript strict 检查通过；全量测试 78 个文件、402 个用例通过；生产构建通过，产物不包含拍摄面板和预设模块。
- 浏览器实际跑完十个预设，检查 Home / Farm / Travel 切换、自由移动与拖动旋转、四季固定机位、雨幕与夜间风暴、HUD 隐藏、9:16 / 16:9、暂停世界、隐藏玩家、预设 Reset、自定义 2 秒轨迹精确终点与环绕。

- 原拍摄模式验证截图在 `artifacts/trailer/`，本次横屏视频在 `artifacts/trailer-samples/`。十段视频已实际输出并检查；剪辑节奏与后续音乐、配音制作交由素材剪辑阶段验收。
- 开发服务器仍输出既有 `FarmMap.ts` 从 `public/models/farm/manifest.json` 导入的 Vite 资源提示（此前树木、界面、季节验证文档已有记录）；本阶段未改动该旧资源路径，实际模型显示和生产构建均正常。
