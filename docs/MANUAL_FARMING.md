# 手工农业

第一条农业生产流程已接入 FarmWorld：领取种子 → 拿起种子 → 站进主田 → E 耕地 → E 播种 → 等待全局游戏时间成长 → E 收割 → 作物进入随身背包。仅实现手工作业与基础表现，农机仍为静态资产。

## 玩家操作

1. 从码头到农场中心，在主路西侧的“初始种子箱”附近按 E。每个存档仅可领取一次，小麦种子、玉米种子、土豆种薯各 8 份。背包无法容纳整包时不发放、不标记领取，腾出空间后可重试。
2. B 打开背包，选择一种种子，点击“拿起种子”将其放到当前选中的快捷栏引用；也可使用原有“绑定快捷栏”分配到不同栏位。关闭背包后按 1～8 切换当前种子。快捷栏本身不持有种子数量。
3. 走进西、中、东任一主田，脚下合法单元出现边框。E 将未耕地或已收割单元变成已耕地；再按 E 从背包扣除 1 份当前所选种子并播种。每次按 E 只处理一个单元，长按不连发。
4. 刚播种 → 幼苗 → 生长 → 成熟均按现有 CropRegistry 和 GameClock 计算。右侧中央交互提示显示作物、阶段、进度及大约剩余时间；未成熟时不能收割。可以继续探索、旅行或回家睡觉推进日历。
5. 成熟时边框变绿，E 提示显示可收获物及产量。收割后产物加入背包，作物表现移除，单元进入 HARVESTED，下次种植前需重新耕地。

小麦完整成长 3 游戏天、每格产出 3 小麦；玉米 4 天、每格产出 2 玉米；土豆 2 天、每格产出 4 土豆。总生长时间从播种时刻起计算，不是按睡觉次数结算。Q 选中种子时提供播种操作指引，实际播种统一使用 E。

没有拿起种子或种子用尽时提示补充/选择种子，土地不变化；背包无法容纳完整产量时提示腾出空间，成熟作物仍在原单元，不丢失、不部分收割。成熟单元收割不受当前手中种类限制。

## 模块边界

| 模块 | 职责 |
| --- | --- |
| `gameplay/farm/ManualFarmingSystem` | 读取土地及当前快捷栏种子，判断单格动作，生成玩家提示，调用统一农业 API |
| `gameplay/farm/FarmSystem` | 已有 till/seed/harvest 与 Inventory 整笔操作；新增一次性种子领取清单和标记 |
| `worlds/farm/FarmInteractions` | 按实际脚下坐标动态生成唯一合法农田目标，和原交通船/种子箱共用 E 交互 |
| `worlds/farm/FarmCropPresentation` | 当前单元边框、耕地纹理、四阶段模型、种子箱外观和实例绘制 |
| `ui/InventoryPanel` | 复用已有网格背包，增加“拿起种子”快捷入口 |

农田单元只从 `FarmSystem.cellAt` 解析，三块主田之外的道路、建筑、草地、田头和预留区没有农田目标。交互还检查玩家贴近地面和当前世界，远离地面不选择单元；每次 E 重新解析位置、土地阶段、种子及容量，避免沿用上一帧过期目标。当前为脚下单元操作，不通过模型命中或镜头方向决定农业状态。

生长时间、阶段、种子 ID、收获 ID 和产量全部来自 CropRegistry；表现层按阶段 `modelAssetId` 加载 [12 个原创建模资源](CROP_STAGE_MODELING.md)，并按 `resourceId` 批量实例绘制。所有作物与土层都是非实体表现，不阻挡农田步行，种子箱有独立碰撞，位于主路外。

同种阶段资源按部件使用 InstancedMesh 绘制。表现层按农田 revision 与全田下一阶段游戏时间检查，只有土地或可见阶段改变才刷新实例矩阵；无需每游戏分钟扫描全田，不创建成长定时器。所有表现对象由 FarmWorld 持有并随世界释放，农业数据由 GameplayFoundation 持有，离岛后持续存在。再次 enter 立即根据 GameClock 重建当前阶段，可直接跨过多个阶段。

## 持久化与兼容

继续使用现有根存档 v2 和 farm 子版本 1。农业存档新增 `starterSeedsClaimed` 布尔标记，旧存档缺字段时默认未领取，种子需主动 E 领取，不在加载时发放。领取先检查整个背包容量，保存回调前提交领取标记和 Inventory 产物；刷新或往返不会重复发放。

土地、播种时刻、作物 `currentStage` 缓存、当前背包及快捷栏选中状态仍走原有 SaveSystem；阶段在恢复日历后重新派生，旧存档缺少缓存时自动补齐。世界 enter 只重建表现，不扣种子、不收获，也不修改生长时间。显示对象不写入存档。

耕地、播种、收割、初始种子领取提交成功后通过公共保存回调立即 flush，土地与背包同时保存。页面隐藏、beforeunload 和 pagehide 也保存最新快照；格式和旧存档规则见 [农业存档](FARM_SAVE.md)。

## 用户待验收

- 三种种子各一次领取，满背包拒绝整包且可重试；成功后刷新不可重复领取。
- 绑定、拿起、1～8 换种后播种正确，每次减少背包 1 份，重复 E 不重复播种。
- 三块田和不同单元独立；在道路、草地、建筑、地头和预留区没有耕地行为。
- 各种作物的四阶段表现和提示正确；暂停不长，倍速/旅行/睡觉后成长，离岛回来与刷新恢复正确。
- 未成熟不能收割；背包满时成熟作物保留；释放空间后收获数量正确，第二次 E 只能重新耕地，不能复制产物。
- 原登船返回 HomeWorld、Home 睡觉/箱子/炉灶、Fishing、Cooking 和鼠标操作继续正常。
- 核对农场中心种子箱路标、碰撞、夜间/风暴与多格种植的显示性能。

本轮按约定仅执行 TypeScript strict 与变更检查；未运行测试套件、浏览器验收或生产构建。
