# Home System

本文保留 Home 阶段的实施记录。后续已接入 [Fishing / Cooking](FISHING_COOKING.md)，炉灶占位提示由实际食谱、制作与食用面板替代；鱼和料理使用同一背包与箱子保存。

储物界面已升级为 [正式背包](INVENTORY_SYSTEM.md) 的 InventoryPanel 双栏网格，支持图标、分类、拖拽、精确槽位转移与全部存入；HomePanel 保留睡觉确认。箱子仍为同一 HomeSystem.chest，旧物品与存档不重建。

## 范围与实施顺序

1. 持久化 HomeSystem：24 格储物箱；复用 Inventory、PlayerProgress、GameplayTime。
2. 绑定已有小屋家具：关闭的门、床、铁皮箱、炉灶；全部经 InteractionSystem / E。
3. 简洁储物面板与睡觉确认；打开面板时停止移动，关闭后保留位置。
4. 睡觉播放完整 6 秒动画：月光海面、星辰隐去、太阳升起 → 次日 06:00、恢复全部体力 → 返回室内。
5. 扩展 v2 存档的可选 home 字段；兼容原 v1/v2，室内刷新恢复到安全入口。

新玩家及尚未包含 home 的旧存档，箱子首次提供木材 8、石头 4；背包仍为空。
已有 home 的空箱子不会重新发放物品。不添加生产、食谱、装备或复杂背包界面。

## 验收

- 门始终保持关闭的模型外观，门外 / 门内按 E 直接进入 / 离开。
- 交互提示在画面右侧中央显示大号 E 按键与操作名称。
- 航海桌、椅子、桌面摆件与地毯靠右墙，中央及入口留出通道。
- 床确认后准确进入次日 06:00，体力满；取消不推进时间；淡入前输入被锁定。
- 两侧物品可存/取 1 个或全部；容量不足不扣物品，不复制。
- 箱子空态、剩余容量、错误提示清晰；Escape/关闭恢复探索。
- 炉灶按 E 打开食谱面板，可制作料理与食用恢复体力；参见后续 Fishing / Cooking 验收项。
- 出入屋、岛屿往返、刷新后箱子不丢失；旧存档、脏数据正常处理。
- 进出屋与航行保持已有鼠标锁定；面板关闭 / 选择后恢复此前锁定模式。主动 Esc 退出过场锁鼠标时不强制重新锁定。
- TypeScript 编译检查；游玩与功能验收由用户完成。

## 操作与接入

入口：主岛小屋门外按 E 入屋，室内蓝门旁按 E 出屋。门保持关闭，无开关门步骤；两个场景由进出屋过场连接。
床旁 E 打开睡觉确认；铁皮箱旁 E 打开存取面板；炉灶旁 E 打开烹饪面板。储物箱与炉灶通过按钮操作，不占用探索 E 键；Esc 返回探索。

`GameplayServices.home` 提供 `chest: Inventory`、`sleep()`、`snapshot()`。
`sleep()` 总是进入下一日 06:00，返回 `{ day, recoveredEnergy }`，保留时间倍速和暂停设置；Game 负责确认和过场，屏蔽重复输入。
`home.chest` 的物品变更自动请求保存，世界切换不会重建箱子。

存档沿用 v2 key，增加 `home: { chest: { capacity, slots } }`。读取 v1 或不含 home 的 v2 时补初始箱子；已有 home 按注册物品与固定 24 格归一化。旧 Home 存档中的 doorOpen 被忽略，箱内物品保留，无需清存档。
屋内保存时旅行世界仍为 HOME，落点标记为 `cottage_entry`，刷新会在门内安全位置恢复。出屋后改为 `home_cottage_exit`。

开发服可用隔离入口直接查看家具：`?world=cottage&view=cottage-bed`、`cottage-chest`、`cottage-stove`、`cottage-door`。
这些预览参数默认不读写正式存档；刷新持久化请使用普通入口游玩。预览不预置额外背包物品、体力消耗或测试按钮。

## 体验修正实现

- `SleepTransition` 使用实际经过时间，完整 6 秒，日历在动画接近结束时只推进一次；倍速及暂停不会加速该动画。`SleepOverlay` 为代码绘制的 SVG 动画，包含被褥呼吸、摇曳窗帘、海面移动、月落、星隐及日出，不使用文字替代动画。
- HUD 将附近交互从底部操作说明中独立出来，右侧中央显示按键卡片；面板与过场期间隐藏。
- 航海工作区 11 个实例一同旋转并平移靠右墙；布局 JSON 与 Blender 组装脚本同步修改，碰撞读取新位置。未重导出二进制 Blender 文件。
- ExploreController 分开处理过场暂停与面板暂停。过场暂停不释放现有 Pointer Lock；面板只为点击暂时释放，关闭 / 确认的用户操作中请求恢复锁定。保留嵌入浏览器拒绝锁定时的拖动观察方式。
