## 当前实现

Three.js 0.186.0 / WebGLRenderer；Vite 7.3.6；Node 24.11.1。MEDIUM 像素比 0.9，水网格步长 0.16；HIGH 步长 0.14，LOW 0.25。普通画质水面在剔除岛屿和瓶肩后为 1500–3000 个实例，由 Ocean.test 验证。鱼 20/32/44；雨 250/500/850；一张 2048² 方向光阴影图。

静态体素按组实例化，共享 BoxGeometry 与材质，实例颜色避免材质分裂。水、鱼、泡、雨复用缓冲；波浪复用矩阵/对象，船四点采样无逐帧闭包分配。HUD 每 250 ms，性能每约 1 s 更新。玻璃使用轻量 Fresnel，无物理透射、后处理或物理引擎。质量切换释放旧水实例及材质，保留共享几何。

2026-09-10，修正普通质量网格后，重新构建并打开新页面，1920×1080 MEDIUM：平静场景 60 FPS、92 calls、96,420 triangles、30 geometries、CPU 0.5 ms、采样窗口最大间隔 18.3 ms、heap 14.2 MB。

数值由 WebGLRenderer.info、RAF 实际时间戳及浏览器 performance.memory 采样。FPS 不是硬编码。CPU 提交不包含完整 GPU 执行时间；三角形/调用数包含阴影且随视角和天气变化；heap 是瞬时 JS 数据，不是总显存。

之前旧开发页面出现 2–5 FPS、739–996 ms 间隔，不能代表新打开的正式前台预览；已由生产版本复测纠正。不能把新采样归因于某个未经证明的单一后台/GPU 原因。

## 内存与 GC 基本检查

源码检查确认热路径复用矩阵、向量及 TypedArray，没有逐水块、逐鱼的每帧对象创建。质量重建显式释放旧水实例及材质；共享几何不误释放。正式页 JS heap 在十几 MB 范围采样，未发现以秒级持续攀升的迹象。没有取得独立 DevTools 长期 GC trace，不把短期采样当作长期无泄漏证明。
