# NPC 底部交流界面

将原居中面板换成底部字幕式交流，保留人物和世界画面。海军蓝透明渐变承托米白台词，阳光金角色名与现有海岛界面统一；右侧话题显示数字快捷键和已聊过状态。菜单可滚动，窄屏与矮屏使用对应排版。

## 操作与边界

- E 靠近交谈；点击台词、E、Space 或继续按钮推进。
- 话题列表支持数字键 1–9、鼠标选择、返回话题和结束对话；Esc 可关闭。
- 普通 HUD 在交流期间隐藏。镜头平滑朝向当前 NPC，不改变玩家位置；结束后恢复原朝向、姓名牌和探索控制。
- 仍由 DialogueSystem 负责台词分支、会面记录和已读记录，完整读完才记录已聊过，中途退出不误记。
- 交易、委托、成长、日历和图鉴仍通过既有动作路由打开。未改变背包、经济、农业及存档格式。
