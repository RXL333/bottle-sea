# Trailer Capture Mode

目标：DEV `?trailer=1` 临时拍摄会话，十个镜头，9:16 优先，正式存档零读写。

1. 在 Game 的存档构造入口使用懒创建的独立内存 Storage；拍摄使用 defaultSave，不读取玩家状态。即使同时传入 persist=1 也禁止正式存档访问。退出通过移除拍摄/预览参数并重新加载普通游戏。
2. 独立 capture 模块拥有自由镜头、序列化起终点/轨迹、预设和临时场景准备。Game 仅增加 DEV 动态加载和拍摄帧更新分支，保留世界与玩法所有者。
3. 面板提供世界、时间、季节、天气、质量、画幅、镜头速度、路径、场景准备、暂停和干净画面控制。F8 隐藏面板；9:16 使用真实摄影机比例和居中渲染区域，不只是裁切线。
4. 十个预设集中定义：瓶外推进、主岛飞越、看海升高、农场升高、拖拉机低机位、联合收割机侧后跟随、牧场生活、四季固定机位、天气延时、黄昏拉远。Reset 重置机位、场景、动画相位和镜头播放时间。
5. 临时作物仍引用 CropRegistry / GameClock / FarmSystem；车辆使用已有位置恢复、驾驶、碰撞与收割；动物动作只覆盖拍摄表现，不新增生产规则。NPC 的临时位置只改当前副本模型。
6. 单元验证存档隔离、路径数学、重置与输入平滑、场景准备；typecheck + 全量 test + build。浏览器实际检查三世界、气候、自由机位、十个预设、HUD/面板隐藏、9:16、重置和退出后正式状态不变。诚实记录未执行项，完成后 Gmail 通知。

不加入视频编码器、专业编辑器、正式玩法状态或生产构建入口。

实施完成。验证结果与使用说明见 `docs/TRAILER_CAPTURE.md`，实际浏览器截图见 `artifacts/trailer/`。录屏制作与声音听感保留给后续素材录制验收。
