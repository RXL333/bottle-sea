# 手工农业生产闭环

沿用 Farm / Crop 数据、统一 E 交互、Inventory / Hotbar、GameClock 和 SaveSystem。保留当前尚未提交的门缝、地图、注册表和数据层修改。不实现驾驶、农机作业、天气/季节或农业装备。按用户约定仅执行类型与变更检查，功能/游玩测试由用户验收。

## 依赖顺序

1. FarmSystem 增加一次性种子领取状态与整笔领取接口，现有 v2 缺字段默认未领取；从 CropRegistry 生成种子清单，不另写作物配置。
2. ManualFarmingSystem 提供单格操作判定、提示与执行，复用 till/seed/harvest；选种读取已选快捷栏，失败不扣种或清除作物。
3. FarmWorld 绑定动态脚下单元目标：必须站在三块主田内、贴近地面；与码头/种子箱共用 InteractionSystem。当前单元边界高亮，提示仍在已有右侧中央位置。
4. FarmCropPresentation 根据 FarmSystem 当前状态和 Registry 资源绘制耕地、播种、幼苗、生长和成熟。按全局游戏分钟与数据 revision 检查变化，仅变化时更新实例批次；不创建成长计时器。已有成熟小麦 GLB 可复用，其余使用明确的占位资源。
5. 背包增加拿起种子的快捷入口，补充 Farm 提示与 Q 引导；在中心增加有碰撞、可识别的一次性种子箱，不占道路。
6. 更新文档、完成自审、运行 TypeScript strict 与 whitespace 检查；不执行测试套件或浏览器验收。

## 完成条件

- 玩家正常领取一次性三种种子（各 8 份），在背包拿起或绑定后按 1～8 选择。
- E 耕地 → E 扣除一份已选种子 → 四阶段成长 → 成熟 E 收割进入背包；离岛睡觉或旅行后阶段正确。
- 道路/建筑/草地/预留区没有耕地目标；跳跃或离开农田不能远程作业。
- 未成熟只能查看生长提示；没有种子、种子耗尽、满背包都保留土地/作物并给明确反馈。
- 刷新恢复农田、背包、选中种子和一次性领取标记；恢复模型不重复扣种或收获。
- 渲染资源随世界装卸释放，农田状态始终由全局 GameplayFoundation 持有；原登船/往返/Home/Fishing/Cooking/箱子接口保持。
