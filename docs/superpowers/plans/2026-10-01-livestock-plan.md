# 第一版鸡牛羊牧场

复用既有 3 鸡、2 牛、3 羊模型与圈舍。保留农业、车辆、背包及多世界逻辑。

1. 独立 LivestockDefinition / LivestockState / LivestockSystem：统一物品 ID，圈舍饲料储备，逐只动物的生产周期、待领取数量与有界活动状态。生产只读取 GameClock，按时间差处理离场 / 睡觉 / 加载。
2. 饲料来自现有背包的小麦或玉米。每份粮食对应一份饲料，每动物每周期消耗一份；鸡蛋、牛奶每日一次，羊毛两日一次。限量储备和待领容量满时暂停新周期，已有产物不消失。
3. 物品扣除 / 发放与牧场数据先共同提交，再调用存档回调。失败回滚；满背包保留待领取产物，重复领取不重复发放。
4. 扩展 GameplayFoundation 与 SaveSystem；旧存档使用安全默认值。仅序列化数据，不保存模型和计时器。
5. 独立世界表现：圈舍与饲槽、小型遮棚、待机 / 行走 / 进食 / 睡眠动作，围栏内有界路径，动态碰撞。近距离 E 投喂 / 收蛋 / 挤奶 / 剪毛，明确剩余时间和产物提示。
6. 验证时间推进、饲料约束、容量边界、恢复与多次同步幂等、存档回调原子性、圈舍与真实模型。执行 typecheck / test / build，隔离浏览器走喂养至领取流程，记录未验收项并发送 Gmail 通知。

执行状态：1–6 的开发与技术验证已完成。typecheck / build / diff 检查通过，55 个测试文件的 239 项通过。浏览器验证包括三类投喂和领取、跨日生产、未到时不可领取、重复领取、满背包与刷新保留、腾出空间领取、真实小屋睡觉后恢复以及质量切换；交通船完整路线本轮未重新走查，玩家主观验收待进行。见 `docs/LIVESTOCK.md` 与 `artifacts/livestock/`。
