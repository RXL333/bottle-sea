# 农场树木建模与接入

参考用户提供的八种体素树：阔叶、杨树、苹果、梨、幼苗、松、垂柳和花树。沿用已有 Blender farm_common 作者工具与 GLB 导出约定，保存独立源文件；不清空或覆盖当前 Blender 文件，不引入第三方模型。

1. 制作有分叉、根部、分层树冠、果实/花朵的原创低模；树冠只导出外表面，按材质合批，地面原点，无烘焙底座或围栏。
2. 新增树木资源目录和小型统一定义。替换原树点位的占位树，按海岸、生活区、林缘安排不同树形，少量加入幼苗。所有树干碰撞与树冠空间不得侵占道路、田头、建筑或农机停放区。
3. FarmModels 使用现有静态合批，叶材质接入原风摆/SeasonalEnvironment；树干、果实和花朵不随树叶整块摇动。仅表现升级，不加入果园收获规则或改动存档数据。
4. 验证 GLB 源文件、轴向/原点/材质/有限几何/体积与预算，检查道路、农田、圈舍与码头；执行 typecheck + test + build，浏览器实际检查树形、四季、质量档位与世界加载。

完成后保存截图、验证记录，发送 Gmail 开发通知。
