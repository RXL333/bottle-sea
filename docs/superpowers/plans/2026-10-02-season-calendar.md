# Season / Calendar 实施与验收

日期直接从现有 GameClock 推导：每季 28 天，每年 112 天，七天一周，初始存档时间保持原值。日历不累计 delta，不建立 Timer。Calendar 只持有通知游标与平滑的展示参数，SaveSystem 保存通知游标，日期依 GameClock 恢复。

1. 统一 SeasonRegistry：季节名称、天气权重、光照/植被色；CalendarSystem 提供日期、近期日期和换季通知。
2. Weather 每个游戏日按日期和季节确定目标天气，沿用原有渐变/风雨音效；手动切换保留到次日。光照和环境共享季节展示参数，世界切换不中断。
3. CropRegistry 定义小麦春/秋、玉米春/夏、土豆春/秋。FarmSystem 只限制新播种；既有作物继续按原生长公式成熟，手工/播种机共用校验。
4. ItemRegistry 鱼类配置季节权重，钓鱼机制与暂存物不变。TradeCatalog 种子季节供应由 CropRegistry 读取；固定价格、饲料、出售、原有农机及升级不变，季节失败不扣款。
5. 海岛 UI 日历面板：28 格季节月历、星期/年/季/累计天数、未来七天、天气倾向、作物季节和鱼讯。HUD 可点击日期或按 L 打开，沿用面板生命周期。
6. 回归测试覆盖边界/跨年/快进/存档/冬季播种失败无资源修改/已有作物成长/季节鱼池/商店交易原子性/天气续接/材质与阴影不回归。执行 typecheck + test + build，再用隔离开发入口实际验证跨季、睡觉、世界往返、天气、农业、钓鱼供应与刷新恢复。

不新增 NPC、节日、灾害、温度生存或其他世界。保留本工作区前一阶段 UI 改动。

实施完成：上述 1–6 项已接入。typecheck、313 项测试和 build 通过；跨季、跨年、实际睡觉、真实岛屿往返、季节供应、旧存档及刷新恢复已实机检查。详细结果与未执行范围见 `docs/SEASON_CALENDAR_VALIDATION.md`。
