# FarmWorld 正式地图基础

本轮只正式化农场岛地图、静态资产及空间接口，沿用 FARM 身份、WorldManager、NavigationSurface、现有码头到达点和 TRAVEL 交互。HomeWorld、TravelWorld、存档格式与已完成玩法不变。游玩及功能测试由用户验收，仅执行 TypeScript strict 与变更检查。

## 布局与尺寸

- 岛体约 72 × 76：南侧现有码头，南部生活/农机中心，中部三块 12 × 18 主田，北部扩田与养殖/牧场预留。工作区保持平地，外围加入体素坡地和低密度植被。
- 农机统一按 Blender manifest 的实际包围盒缩放 0.5；最宽收割机约 2.26，主路宽 5。拖拉机与拖车纵向尺寸加牵引间距约 3.88，预留直径 10 的静态掉头空间。此尺寸是未来车辆控制器的地图约束，当前不实现驾驶物理。
- 主田两端各保留 10 深的无障碍地头，中间 10 宽间隔放置道路；农机、工具和装饰不得占用田块与地头。独立停放车辆，留存资产实例引用。
- 统一 FarmMap 定义固定区域 id、边界、道路、田块 grid 原点/格数/格宽、地头、停放位与导航范围。渲染和导航共同读取这些数据；当前不产生农业运行状态或修改存档。

## 实施顺序

1. 定义 FarmMap 与场地分区、车辆尺寸预算；规划 FarmLayout 建筑、机械及围栏。
2. 更新 FarmTerrain 平台/道路/三块空田/预留草地/外围坡地，视觉高度与地面查询一致。
3. 使用已有 GLB，去掉占位麦田；环境合批，车辆实例独立保留。修正建筑、树、围栏的碰撞与可行走基础。
4. 扩大 FarmWorld 导航范围和局部环境覆盖；FarmOcean 覆盖全岛海岸并复用 WaveMath，不修改 TravelOcean。保持船位/交互/到达点不变。
5. 更新受布局影响的已有检查与文档，执行 tsc 与 whitespace 检查；记录用户待验收路径。

## 用户待验收

码头下船 → 中心 → 三块空田及地头 → 西侧农机区 → 北侧畜舍预留及牧场 → 原码头返航；核对建筑/车辆碰撞、外围坡地、画质、夜间/风暴、重复往返与普通存档恢复。实际驾驶的转向半径将在 Vehicle System 实现时在上述尺寸约束内验证。
