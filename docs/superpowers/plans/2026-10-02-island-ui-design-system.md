# 海岛生活 UI 统一改版

参考用户提供的海岛界面风格指南：纸面内容、海军蓝框架、木棕细节、阳光金强调，保留所有现有游戏功能与数据流。

## 实施顺序

1. 建立共享颜色、字体、边框、阴影、状态与组件样式，提供公共标题/关闭按钮和进度条展示帮助函数。
2. 成长手记、背包/储物箱、详情、快捷栏作为基准。背包沿用固定高度和内部滚动，详情变化不能改变整体尺寸。
3. 迁移烹饪、交易、航行、休息和全部游戏 HUD 提示；不改农业、经济、车辆、交互或存档规则。
4. 编写新界面的使用规范，执行 typecheck、test、build，浏览器检查主要界面和窄屏布局。

四项实施已完成。共享规范见 `docs/UI_STYLE_GUIDE.md`，自动检查、实机操作、截图及未通过/待复核项见 `docs/UI_REDESIGN_VALIDATION.md`。视觉验收由用户进行；不将待复核项计入通过。

## 验收

- 默认/悬停/选中/禁用/完成状态明确且一致，键盘焦点可见。
- 主界面不再使用大块深绿；纸面正文、按钮和数量清晰，航海装饰克制。
- 背包分类、物品操作、储物转移、快捷引用和面板关闭行为保持正常。
- 主要弹窗在窄屏、低高度下可滚动，无横向溢出；成长与存档逻辑测试不回归。
- 输出可复用规范以及真实验证记录，邮件通知如实区分检查通过与待用户验收。
