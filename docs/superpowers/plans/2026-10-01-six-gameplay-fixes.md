# 六项玩法体验修复

保留主角接入及已有 Home / Inventory / Farm / Vehicle / Economy / Save 架构。

1. 检查现有犁模型：补齐两侧支撑轮及语义转动节点，重新导出既有资产，不改耕地宽度 / 土地规则。
2. 固定背包对话框与内部网格区域尺寸，详情与操作独立滚动，切换 / Hover 物品、分类及储物箱不导致对话框跳动；验证窄屏与低高度布局。
3. 排查叠面深度冲突和移动阴影：处理农场道路、广场与农机区地面交叠，检查主岛格块及农业叠层，固定适当阴影范围 / 光源方向，保留建筑与机器阴影并增加几何回归检查。已确认主岛基础格块无重复顶面。

5. 主岛交易由现有远海帆船承担，基于 GameClock 设置每日长时靠岸与离岸周期；独立商船泊位远离交通船。靠岸交易、离岸提示、菜单期间离港交易检查、安全航线与重新进入恢复共用游戏时间，复用原经济原子转移。
6. 用户已确认鼠标控制农机转向，保留 A/D；左键拖动仅用于观察镜头，松开平滑复位，捕获丢失 / 失焦 / 上下车重置；镜头继续使用碰撞裁剪。
