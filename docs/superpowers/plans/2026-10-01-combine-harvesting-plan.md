# 联合收割机驾驶与收割

1. 将现有车辆运动、车轮与导航参数化，保持拖拉机行为兼容；现有联合收割机 GLB 使用四个原轮轴、header / header_reel / unloading_auger。两车动态碰撞互相避让，驾驶与镜头共用 VehicleController。
2. CropRegistry 标注首版机械收获支持（小麦、玉米）；割台实际宽度使用共享连续扫幅。J 割台抬落、L 作业开关分离，抬起或下车自动停止。
3. 增加总量 60 份的车载粮仓，统一 Inventory 负责堆叠与转移；FarmSystem.harvest 扩展目标接收接口，默认仍为背包。只有完整产量可接收时收割对应单元，满仓停止，未成熟及土豆保持原状。
4. 谷仓门前设置卸货范围，U 停车卸货；既有 Inventory 原子转移写入持久仓库，失败保留所有物品。复用背包网格查看与取出谷仓物品，为后续卸至拖车保留目标库存接口。
5. 保存两车独立位置、割台 / 作业开关、粮仓与谷仓；收割保存回调能看到同步的车辆、粮仓和农田状态。兼容旧存档和拖拉机挂接 / 播种 / 犁地。
6. 覆盖收割成熟 / 不成熟 / 土豆、满仓 / 余量不足、重复与连续扫幅、混粮、卸货失败 / 成功 / 再次卸货、保存恢复、真实 GLB 行驶碰撞及安全下车。执行 typecheck + test + build 与实际玩法验证，保存截图并发送 Gmail 通知。
