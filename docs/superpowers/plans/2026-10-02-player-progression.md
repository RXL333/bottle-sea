# Player Progression

目标：使用成功提交的玩法事件形成轻量里程碑路线；不复制已有物品、土地、车辆、货币，不添加 RPG 数值。

1. 增加静态 ProgressionRegistry、纯数据 ProgressionSnapshot 与全局 ProgressionSystem。
2. 在钓鱼、料理、睡觉、农业提交、畜牧领取与交易成功处接入独立活动回调；旅行抵达、小屋进入、实际车辆移动由现有控制层记录。
3. 新游戏首次料理解锁暖汤、烟熏鱼；首次出售解锁现有容量升级。基础玩法保留开放。旧存档缺失 progression 时只保留原有访问权限，不凭背包物品虚构里程碑。
4. 集成 SaveSystem v2 可选旧字段迁移、成长面板、当前目标和独立完成提示；未来内容明确标为尚未实现。
5. 验证事件幂等、失败和空操作、资源交易、存档恢复和旧档兼容；执行 typecheck / test / build；浏览器检查界面和实际玩法事件。

验收边界：不开放深海、遗迹、委托或季节，不改农业规则，不自动奖励物品或金币。先做再记录，已完成操作没有路线顺序要求。
