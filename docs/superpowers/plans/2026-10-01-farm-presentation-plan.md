# 农业表现打磨

仅修改表现，保留 Farm / Crop / Inventory / GameClock / SaveSystem 的规则及数据格式。

1. 六种土地状态分别展示，保留三种作物四阶段 GLB，以材质批次合并实例几何、GPU 风摆和质量档位控制保持流畅。低档关闭风摆 / 作物阴影，状态模型和标识始终保留。
2. 从实际农业状态变化产生耕地 / 播种 / 收割表现事件；首次加载及恢复不播放旧事件，失败与重复操作不产生成功特效。
3. 固定容量体素粒子池，呈现土块、播种落粒、收割碎屑和行驶扬尘；限制距离、每帧事件及农机数量，低档关闭粒子。
4. 在原声音开关和 AudioContext 内增加有数量上限的发动机 / 作业循环与短促作业音效；依据车辆速度、占用、农具抬落、作业开关和真实成功变化同步，停车 / 离场 / 暂停 / 静音后及时停止。
5. 复用交互和 HUD 提示，增加地块状态 / 阶段信息与简明土地图例。特效不能把未成熟、保护、满仓或失败画成成功。
6. 验证规则和存档未改变、六状态和十二阶段渲染、正确变化事件、失败无反馈、池和音频上限、质量切换、恢复不重播。typecheck + test + build；隔离浏览器检查大面积作物和实际农机作业，保存截图并通过 Gmail 如实报告结果。

实施与验证已完成；详情见 `docs/FARM_PRESENTATION.md`。音效听感和操作舒适度保留为玩家主观验收项。
