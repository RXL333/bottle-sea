# 基础经济与交易

保留已完成背包、Home / Fishing / Cooking / Farm / Livestock / 车辆及旅行系统。固定价格，玩家出售统一背包内产品获得金币，再购买种子、饲料、增购收割机和容量升级。

1. TradeCatalog 集中价格与商品规则；EconomyState / EconomySystem 保存整数金币、交易序号、购买记录和有限升级等级。交易预检资金、物品、容量、单次请求序号及交付条件；先共同提交双方数据再通知存档，失败回滚。
2. 通用饲料注册为统一 Item，继续由 LivestockSystem 消耗。Inventory 仅增加不缩容的容量 API；谷仓 24 / 36 / 48 格、所有收割机粮仓 60 / 90 / 120 份。SaveSystem 先恢复经济等级，再恢复对应容量的仓库及车辆货物。
3. 初始金币 100；旧存档无经济字段时安全初始化。新增一台购买用联合收割机，独立稳定 ID，复用原模型、驾驶、碰撞、收割、卸货及存档。原有车辆不回收、不收费。农场码头购买时检查指定停放位；被车辆、动物或玩家占用时不收费。已买过不再次交付。
4. 主岛与农场码头添加独立商船和 E 交易入口，保留交通船。模态交易界面显示商品分类、单价、数量、总价、余额、接收容量和失败原因；背包、驾驶和时间暂停行为复用 Game 既有面板流程。
5. 覆盖买卖原子性、请求重放、资金 / 物品 / 容量不足、升级即效及恢复、旧存档保留、交付阻挡、购买车辆驾驶和收割卸粮。执行 typecheck / test / build，隔离浏览器验证完整买卖、升级、购买、满背包与恢复；如实记录待验收事项，发送 Gmail 通知。

实施已完成。全量检查通过，57 个测试文件 / 256 项测试。隔离浏览器交易、交付、扩容、满背包保护、刷新恢复、主岛共享状态及上下车 / 作业控制验证通过。持续驾驶手感留待人工验收，详见 `docs/ECONOMY.md`。
