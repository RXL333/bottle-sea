# 主角建模与游戏接入

按用户图纸制作原创低多边形角色：草帽 / 蓝帽带、棕发、米白衬衣、蓝色背带裤、棕色背包和短靴。沿用已完成资产的 Blender 网格作者工具模式，不覆盖当前作物工程。

1. 在连接的 Blender 5.2 中新建独立角色场景；制作有体积的面部与服装细节、材质色板和明确活动节点。导出脚底原点、+Z 前向的 GLB、可编辑 blend、资产尺寸 / 节点元数据及预览图。
2. 新增独立 PlayerCharacter 表现模块：仅加载一次，第一人称隐藏头帽和背包以免挡镜头，显示身体；按现有脚底高度缩放。车辆第三人称显示完整坐姿，角色髋部对齐现有 seatPosition，跟随车辆。站姿、步行、跑步和坐姿共用模型节点，不增加角色碰撞体或修改控制、农业和存档。
3. Game 仅接入加载、显示状态、质量与逐帧表现更新；世界切换和面板 / 过场期间正确隐藏或暂停。模型属于全局表现层，不归世界卸载释放；不保存 Mesh、动画或模型运行对象。
4. 增加真实 GLB 节点、尺寸、活动姿态、坐姿定位、第一人称头部隐藏和资源释放验证；执行 typecheck / test / build。核对 Blender 预览和浏览器中上车 / 下车画面，记录未执行或待人工验收项，并按既有授权通过 Gmail 通知。

范围不包含第三人称步行控制重写、角色编辑器、装备系统或整套工具作业动画。
