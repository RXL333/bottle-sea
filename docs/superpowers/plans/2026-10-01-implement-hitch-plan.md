# 农具挂载与分离

复用拖拉机、InteractionSystem、FarmWorld、全局 GameplayFoundation 与 SaveSystem。仅处理连接、跟随、分离、碰撞和保存，不执行农业作业或库存转移。

1. 核对 GLB 原点、边界与挂点，补齐 tractor 的 Hitch_Front 及 plow / seeder / farm_trailer 的 Hitch_Front。同步 Blender 源、生成脚本、GLB 清单；不重建几何或覆盖用户当前场景。
2. 添加集中农具定义与车辆存档 v2 扩展：固定农具身份、停放坐标、挂接端口、唯一关系。旧车辆 v1 / 无字段存档安全迁移，保存只含数据。
3. 复用独立模型实例，农具使用动态碰撞。挂接必须停稳、兼容、距离与朝向正确；预测组合占地后原子提交。刚性农具保持相对朝向；拖车按连接点运动转向并限制折角，倒车不翻折。
4. 每个车辆运动子步验证车身与所有已挂农具，再提交跟随位置。分离验证地面、障碍、车辆及玩家位置，失败不改变关系；完整保存车 / 农具位置与关系。
5. 沿用 InteractionSystem：驾驶 E 下车、H 挂接/分离；步行连接点 E 操作。HUD 给出农具名称、端口和条件反馈；镜头跟随距离适应后挂农具。
6. 添加状态迁移、错误条件、原子关系、前后挂点、转弯 / 倒车、碰撞、分离、真实 GLB 与 SaveSystem 恢复的回归测试。执行 typecheck、test、build，通过浏览器实际验证玩法与刷新恢复。
7. 记录结果；通过 Gmail 向用户指定邮箱发送完成 / 失败通知，明确测试范围及任何未通过项。
