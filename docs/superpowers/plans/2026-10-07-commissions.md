# 岛民委托实施计划

复用现有 NPC 对话、Inventory、Economy、Progression、GameClock 与 SaveSystem，不添加平行库存或金币。

1. 静态 CommissionRegistry：四位 NPC 的固定小规模委托、交付/真实生产/探索目标、金币/物品/解锁奖励；无期限、无随机任务链。
2. CommissionSystem：保存接取与完成时间及接取后真实生产计数；交付实时读取背包，探索读取现有发现与里程碑。数量不足与奖励容量不足保持资源不变；完成永久防重。
3. 扩展既有成功事件的产物明细，手工与农机收割共用 FarmSystem；钓鱼暂存领取不能重复计算。批量保存委托、库存、金币与解锁的完整提交结果。
4. NPC 对话入口与 J 委托手记；统一羊皮纸/海军蓝 UI。手记可查看全部，接取/交付只能在发布者处；关闭恢复原控制。
5. SaveSystem 安全默认、数据校验、旧存档兼容；正常游戏无开发验证按钮。
6. typecheck、全量 test、build；独立本地端口实际浏览器检查四位 NPC、接取、生产进度、提交、防重、容量/数量不足、睡觉与旅行、刷新恢复；逐项记录结果并 Gmail 通知。

开发及上述验证已完成：12 份固定委托，73 文件 / 352 测试通过；实际浏览器完成 8 份并覆盖各目标类型。架构见 `docs/COMMISSIONS.md`，逐项结果与未执行范围见 `docs/COMMISSIONS_VALIDATION.md`。
