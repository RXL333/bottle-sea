# FarmWorld 天气视觉升级

复用 WeatherSystem、GameClock、DayNightSystem、WorldManager、SoundSystem 和 SaveSystem；不修改农业、动物、车辆或交易规则。

1. 扩展全局天气表现参数：晴、阴、雨、风暴及平滑云量、风、降雨、湿润度；旧 storm/intensity 字段兼容，保存过渡状态。暂停时不推进，跨世界不重置。
2. 农场拥有风格化渐变天穹、两层体素云、日/月与星空；色彩随昼夜与天气渐变。远处海面与线性远雾使用相同地平线颜色，主要道路不被雾遮住。阴影投影继续固定，晨昏使用无阴影暖色补光。
3. 调整现有雨幕为农场局部真实尺寸，风暴斜雨，限制雷电幅度与频率；作物、合批树木/草和风车共用全局风参数。地面/土壤/静态建筑材质逐渐湿润和恢复，保留地块状态色。
4. 圈定有顶建筑遮雨，复用室内音频混音，过滤与音量渐变；离开建筑恢复。低档减少云、星和雨数量、关闭草木风动画及辅助灯。
5. 开发检查点提供天气/时间、室内外、世界切换及真实旅行入口，便于通过浏览器 UI 验证，生产版本不带测试控制。记录截图、状态和性能边界。
6. 针对过渡、旧/新存档、雨范围/遮雨、雷电频率、天空/雾可见性、风/湿度不会修改农业数据增加必要测试；执行 typecheck + test + build 并检查实际 shader 编译及所有天气与昼夜组合。
