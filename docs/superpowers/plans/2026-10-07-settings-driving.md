# 设置与驾驶优化

基于已有控制、渲染、音效和存档模块实现，不改变农业规则。

1. 建立可校验、兼容旧存档的偏好状态。画质和钓鱼方式继续使用现有存档字段。
2. 添加统一设置面板：画质、渲染精度、帧率显示、声音、视角、三种车辆转向方式、转向/观察灵敏度、跟随距离、钓鱼操作和恢复默认。
3. 设置打开时停稳车辆、暂停输入，关闭后恢复原控制与鼠标锁定；禁止面板操作触发农具作业。
4. 降低鼠标默认转向系数。驾驶镜头碰撞采用近处模型筛选，保留精确几何与近裁面保护，减少重复扫描。
5. 验证偏好恢复、三种转向模式、设置暂停、镜头碰撞与观察复位；执行 typecheck、test、build，实际浏览器检查并记录性能结果。
