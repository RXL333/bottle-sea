# 拖拉机挂犁耕地

沿用现有 FarmWorld、拖拉机 / 农具 GLB、HitchSystem、InteractionSystem、FarmSystem、CropSystem、GameClock 和 SaveSystem。本文记录犁地交付；后续已接入 [播种机作业](TRACTOR_SEEDING.md)，拖车仍只支持挂接 / 分离。

## 操作

1. 靠近拖拉机按 **E** 上车，停稳并对准犁地机连接点后按 **H** 挂接。已有前后挂点兼容规则保持不变。
2. 驾驶中按 **J** 切换抬起 / 落下，模型围绕连接销平滑抬升。新挂接、分离及缺少状态的旧存档默认抬起。
3. 落下后，W / S 前进或倒车经过三块主农田，即可耕地；转弯也连续作业。抬起、停住、分离、挂接瞬间或恢复位置均不耕地。
4. 原有 Space 刹车、E 安全下车保持不变。下车后可以在同一土地播种或继续手工操作；车旁 E 优先处理车辆与农具，避免脚下播种提示阻挡上车。

驾驶 HUD 显示农具抬落、实际宽度、停止 / 农田外 / 已耕地 / 作物保护反馈及本次新增格数。计数仅为当次作业反馈，重新进入或切换抬落会重置；土地和抬落模式正常保存。

## 作业范围与状态

- `ImplementRegistry` 集中定义四片真实犁刃的作业范围：资产空间 X [-1.33, 1.39]、glTF Z [-0.635, -0.11] 米。现有农场模型缩放 0.5 后，作业宽度 **1.36 米**；侧边深度轮不计入犁刃宽度。
- `ImplementSweep` 使用前后足迹的连续扫过多边形，并按距离 / 角度细分转弯，包含旋转弧线余量。车辆沿用现有 120Hz 最大子步长，只在通过碰撞检查的实际移动后提交作业，连续行驶和倒车没有离散采样漏格。
- 沿用农业网格的单元中心覆盖规则；`FarmSystem.cellsInArea` 先限定附近行列，再检查多边形。只有三块已定义农田内的单元进入作业，没有道路、建筑、草地或扩展预留区的数据可被修改。
- `PlowingSystem` 对扫过单元去重，仅将 **UNTILLED / HARVESTED → TILLED**，调用与手工耕地相同的 `FarmSystem.till`。所有有作物的单元（SEEDED / GROWING / MATURE）都保留。重复经过已耕地不改状态、不增加收益。
- 农具抬升只改变显示层，连接销、地面姿态、碰撞接口及作业查询不读取动画偏移。农田渲染沿用共享 revision，当帧显示耕地结果。
- 耕地不消耗种子、不产生物品，不存在第二份库存；背包满也能耕地。播种和收割继续使用已有 Inventory 事务接口。

## 保存与恢复

沿用外层 SaveData v2 和车辆子结构 version 2，作业农具姿态保存可序列化 `workState: 'RAISED' | 'LOWERED'`。归一化时缺失 / 非法模式默认 RAISED，拖车不接受作业模式。没有持久化 Mesh、动画角度、输入或乘坐状态。

切换抬落先提交整组车辆 / 农具姿态和连接关系，再调用原有即时保存。每次实际耕地也先记录当前整组姿态，再由 FarmSystem 的既有变更回调保存土地，避免土地已耕但车辆仍是上一子步位置。原有上下车、离页和失焦保存入口继续工作。

恢复时重建农具显示、合法关系与地面位置，不执行耕地扫描。已挂接的犁保留抬落模式；未挂接的犁安全抬起。农业状态仍由现有农业存档恢复，作物仍由 GameClock 投影生长。
