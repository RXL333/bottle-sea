# Fishing / Cooking

后续已接入 [正式背包](INVENTORY_SYSTEM.md)。物品名称、图标、分类、堆叠数量、鱼类属性与食物恢复值统一由 ItemRegistry 定义；本文件中的 Catalog 仅保留食谱规则或注册表视图。钓鱼奖励和制作 / 食用均通过同一 Inventory，玩法流程保留。

## 范围与实现顺序

1. 注册 6 种鱼、4 种食物与 4 个食谱，旧存档仍沿用 v2。
2. Inventory 增加整笔材料交换：预检、扣料、产物入包一次提交，失败不扣料。
3. FishingSystem：抛竿、等待、限时咬钩、挣扎抵抗、收杆、收鱼；Game 协调统一 E、鼠标张力输入、距离取消、反馈；三维鱼竿/浮漂可视化。
4. CookingSystem：食谱预检、短烹饪过程、制作入包、食用恢复体力；独立简洁炉灶与随身食物面板。
5. 接入状态保存、家园钓鱼台导航、UI、说明和 TypeScript 编译检查。

## 初版规则

- 钓鱼台提供钓竿，不需要装备或鱼饵系统。每次抛竿消耗 6 体力，约 0.85 秒抛竿、4～8 秒等待、2.8 秒收杆窗口、1.1 秒收杆。
- 六种鱼：沙丁鱼、竹荚鱼、鲭鱼、海鲈鱼、红鲷鱼、金枪鱼；相对权重为 35 / 24 / 18 / 12 / 8 / 3，均可在主岛钓到。
- 挣扎参考[原神官方钓鱼说明](https://www.hoyolab.com/article/750889)：提钩后用横向张力槽与竖条追随移动的黄色最佳区；区域内增长钓鱼进度环，区域外下降，满进度才收鱼。使用本项目绘制的 UI 与程序模型。
- 默认长按左键张力增加，松开减少；R / HUD 操作模式按钮可切换点击模式，每次点击增加张力，停止点击后回落。模式存档。鼠标锁定及拖动备用模式均从画布接收左键；挣扎时暂停观察旋转，移动走离钓鱼台仍可取消。
- 常见 / 少见 / 稀有鱼最佳区宽度为 34% / 28% / 22%；不同速度移动，周期猛烈挣扎加快张力变化并变橙色。初始进度 25%，首秒提供输入宽限；零进度持续 1.5 秒或挣扎满 90 秒后鱼逃脱，危险区变红色。
- 钓鱼逻辑使用真实帧 delta，不受游戏时间倍速或暂停加速；正常日历仍随世界时间推进。切换标签页收竿，烹饪面板在后台停止推进。
- Esc 或离开钓鱼台取消；未及时收杆鱼逃走。取消不退回抛竿体力。进行中的钓鱼不在刷新后恢复。
- 开始前检查体力与背包容量；收杆时重新检查。若期间背包满了，鱼进入持久化暂存，腾出空间后在钓鱼台按 E 领取，不丢弃、不重复奖励。
- 烤鱼：任意鱼 1 → 食物 1，恢复 20；海鲜汤：任意鱼 2 → 食物 1，恢复 45。
- 香煎鲈鱼：海鲈鱼 1 → 食物 1，恢复 35；烟熏鱼：任意鱼 1 + 木材 1 → 食物 1，恢复 30。
- 烹饪消耗 2～3 体力，过程 3 秒；制作完成才整笔扣料，取消不扣料。食材来自随身背包，箱子内食材需先取出。
- 食用只消耗已制作食物，恢复量按体力上限截断；满体力不消耗。原鱼不能直接食用。

## 待用户验收

- 可走到主岛钓鱼台，E 完成抛竿 → 等待 → 咬钩 → 提钩 → 控制张力 → 收杆，获得一条鱼进背包；有对应模型和反馈。
- 长按与点击模式都能控制竖条；最佳区持续移动，进度区内增长/区外下降，满进度才奖励。常见与稀有鱼难度不同，猛烈挣扎橙色/濒临逃脱红色可辨识。
- 快速重复 E 不产生额外奖励；漏钩、离开、Esc、低体力、满背包处理明确。
- 鱼可在箱子存取；刷新 / 进出屋 / 岛屿往返后物品与体力保留。
- 炉灶可选食谱与优先鱼材，正确显示所需材料及不可制作原因；制作和取消保持物品一致性。
- 食物进入背包，可在炉灶与随身食物面板食用，恢复体力；体力已满时数量不减。
- 睡觉后的新一天可继续钓鱼与烹饪；原门、布局、交互提示和鼠标锁定修正保持。

本轮按用户要求只实现功能与编译检查，不运行游玩或自动测试；不提交、部署或提前实现农业、装备、Buff 与经济。
