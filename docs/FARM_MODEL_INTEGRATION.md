# 农场模型接入

目标：使用已制作的 GLB 替换农场岛占位物件，保持旅行、存档、碰撞与通行可用。明确排除 kitchen_stove 和 storage_set 及其组件；它们留给主岛。床置于可进入的农场小屋。

实施顺序：
1. 核对实际模型尺寸与人物视点（离地 0.44），规划人、动物、农机、建筑比例及空地。
2. 完善小屋空心墙体、门与室内支撑；补树、作物等必要农场资产。
3. 加入按需 GLB 加载、资源释放、静态合批；失败交由已有世界切换恢复流程。
4. 替换房屋、围栏、码头、交通船视觉；布置农机、动物、风车、水塔与床。
5. 同一布局驱动模型放置和导航：出生点、道路、码头、畜栏门口、小屋入口保持可通行。
6. 验证实际 GLB 加载、尺寸、禁止资产排除、碰撞、异步失败/释放、往返旅行；构建与真实网页视觉检查。

交付以本地网站实际渲染和自动化验证为依据，不自动发布远程站点。
