# 农场树木建模与接入验证

日期：2026-10-03（Asia/Shanghai）。

## 完成内容

- Blender 制作阔叶树、杨树、苹果树、梨树、果树幼苗、松树、垂柳、花树；保存八份独立源文件、集合场景和预览图。
- FarmWorld 原来的 20 处单一占位树改为混合树种，新增 5 处生活区/苗圃树，共 25 处。保留主要道路、农田、田头、交通船和农机停放空间。
- `FarmTrees` 使用作者脚本生成的统一资源元数据；树干碰撞使用小范围实体，树冠不成为大型空气墙。
- 复用现有静态材质合批、叶片风摆、季节变色和质量档位。树干、果实与花朵分离；没有修改农业规则、车辆控制、Inventory 或 SaveSystem 格式。
- 八个 GLB 合计 1,565,092 bytes；单树 2,552–5,144 三角面，无外部纹理。装饰树按地图确定性加载，无新增存档字段。

## 实际浏览器检查

使用开发预览 `?world=farm&view=farm-trees&hour=12&day=1&weather=CLEAR` 检查实际 FarmWorld 点位，不复制替身场景。预览默认不写入玩家存档。

- 八种模型逐一查看：树冠、分叉、根部、杨树浅色树干、松树层叠轮廓、垂柳下垂轮廓、幼苗支撑、红苹果、黄梨和粉色花树正常显示。
- 春 → 夏 → 秋 → 冬：现有日历连续推进；树叶从绿色转向秋色、冬季霜色，树干保持木色；过渡使用原季节混合。
- MEDIUM / HIGH / LOW 切换：模型正常，冬季轻雪可见，LOW 降低环境粒子和云层数量；本机检查视角约 54–60 FPS。该数字仅为本机短时观察，不代表全部硬件的性能保证。
- 开启时间后风相位推进，新树复用现有树叶风摆。
- 实际交通船完成 FarmWorld → HomeWorld → FarmWorld 两次航行；返回后新树正确重新加载，浏览器未记录资源错误或警告。
- 晴天白昼及雨天夜间均检查了新树显示，刷新/重新加载后模型仍可显示。
