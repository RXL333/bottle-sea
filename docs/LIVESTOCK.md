# 第一版鸡、牛、羊牧场

FarmWorld 复用原有 GLB：鸡舍 3 只鸡、牛棚 2 头牛、羊圈 3 只羊。补齐圈舍围栏、饲槽及小型遮棚，动物仅在各自安全边界内活动，不进入农田或海岸。车辆和步行控制使用动物的动态碰撞体。

## 玩家操作

- 把收获的小麦或玉米放在统一背包中，靠近各圈舍饲槽按 E 补充。一次最多 5 份，饲槽未分配储备最多 24 份；优先使用快捷栏选中的可用饲料，否则依次使用小麦、玉米。种子不作为饲料。
- 每份饲料为一只动物开始一个生产周期。鸡蛋、牛奶需经过 24 个游戏小时，羊毛需经过 48 个游戏小时。周期从获得饲料时开始，不以午夜直接发奖。
- 动物在白天待机、行走或进食，22:00–06:00 睡眠。睡眠继续计算已经获得饲料的生产周期。
- 待领产物上方显示金色标记；靠近动物按 E 收蛋、挤奶或剪毛。提示同时说明待领数量、剩余时间或尚未喂养。
- 领取只转移背包能容纳的数量；背包已满时产物留在动物身上。每只动物最多暂存 20 份，达到上限后暂停新周期，保留尚未分配的饲料。
- 鸡蛋、牛奶和羊毛使用 ItemRegistry 的统一图标及堆叠定义，可存入既有箱子。此阶段未新增料理配方、直接食用或出售规则。

## 架构与存档

`LivestockDefinition` 定义种类、生产配置、圈舍与初始动物；物品数据仍只由 ItemRegistry 管理。`LivestockState` 保存纯数据并处理有界事件补算，`LivestockSystem` 负责 GameClock、喂养及 Inventory 事务。FarmWorld 的独立 `LivestockPresentation` 与 `LivestockInteractions` 负责模型动作、碰撞、提示及 E 交互。

SaveSystem 的现有 v2 存档新增 `livestock`：圈舍 ID / 储备、动物 ID / 种类 / 所属圈舍 / 位置 / 朝向 / 行为 / 待领数量、喂养时间、下一次产出时间和最后同步时间。旧存档缺少字段时恢复初始 8 只动物，饲料与待领数量为 0。

生产使用现有全局 GameClock；离场期间不建立逐帧模拟或逐只 Timer。重新进入、睡觉、时间快进或加载时，按游戏时间差补算有限饲料对应的周期。现实时间关闭页面不会自动增加游戏时间。领取完成的周期不会在刷新后再次发奖。饲料扣除和产物入包之前先提交匹配的牧场状态，Inventory 的存档回调能同时读取两边结果；交换失败回滚牧场状态。

表现层只使用少量独立动物对象，腿、头与翅膀通过已有语义节点制作轻量动作；LOW 档关闭动物阴影及行走摆腿等装饰，保留状态姿态、产物标记和所有交互。

## 验证记录

新增数据、真实 GLB / FarmWorld 集成和 SaveSystem 测试，覆盖生产时间、离场后大量时间补算、缺饲料、待领上限、背包满及部分堆叠领取、重复领取、交换失败回滚、存档回调一致性、位置边界、夜间睡眠及旧存档恢复。

隔离开发浏览器通过实际 E 和现有时间 API 验证三类投喂、收蛋、挤奶、未到时间不可剪毛、两日后剪毛、重复领取、满背包保留、刷新恢复及腾出空位领取。通过开发入口定位小屋，实际使用床与 6 秒睡觉过场，返回农场时奶牛待领量按跨过的生产周期增加。MEDIUM / HIGH / LOW 画质切换正常，浏览器未记录控制台警告或错误。开发专用 checkpoint / 时间按钮只在 DEV 的 `farm-livestock*` 视图中出现；`fixture=1` 明确填充测试物品，测试截图中的满堆物品并非自然生产数量。
