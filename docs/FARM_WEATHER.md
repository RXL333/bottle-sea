# FarmWorld 天气视觉与验收记录

2026-10-02。复用全局 `WeatherSystem`、`GameClock`、`DayNightSystem`、`SoundSystem` 和 v2 `SaveSystem`。农业、车辆、畜牧、经济、物品转移规则没有增加或改写。

## 游戏中的效果

- 农场工具栏的天气按钮循环：晴天 → 阴天 → 雨天 → 风暴。沿用原有天气控制入口，不增加自动天气日程。
- 晴天有渐变蓝天和两层缓慢移动的体素云；阴天云层扩大、光照柔和；雨天启用雨幕、雨声和湿润材质；风暴云更暗、风更强、雨更斜。
- 清晨有暖色地平线和薄远雾；正午明亮；黄昏橙紫；晴夜有星空、冷色月光及小屋、谷仓、农机棚入口暖光。
- 保留稳定的太阳阴影投影，晨昏增加无阴影的低角度补光。农场步行与驾驶的远裁剪距离至少 220，避免控制器重置为 40 后截掉天空和远云。
- 云、雾、太阳和月亮方向、光色、风和雨强度渐变。云在循环边界先淡出，避免突然跳到另一侧。土地、农田及建筑材质随全局湿润度响应；雨停后缓慢干燥。
- 作物、合批树木、野草和风车使用同一全局风相位；湿地减少扬尘。风和湿润效果只操作表现对象，不修改土地与作物数据。
- 农场有顶的小屋、谷仓、农机棚按屋顶范围遮雨；独立 Home 小屋场景也遮雨。室内雨声音量约为室外 20%，风声降低并加低通；雷声额外减弱。
- 雷电首次约 2 秒后出现，随后间隔 12～26 秒。天空和光照闪光受限，不使用强烈全屏白闪。

## 性能与存档边界

| 质量 | 云团 | 星点 | 雨线 | 建筑辅助灯 | 草木、作物风动 |
| --- | ---: | ---: | ---: | ---: | --- |
| LOW | 12 | 0 | 250 | 1 | 关闭 |
| MEDIUM | 24 | 90 | 500 | 2 | 常规 |
| HIGH | 36 | 160 | 850 | 3 | 增强 |

一个渐变天穹、固定数量的云团、星点、雨线及材质引用；没有逐株天气 Timer，也不逐帧遍历整棵场景树。树木维持合批，作物维持原有 Instancing。风动深度材质与可见材质同步，共享体素资源不会被农场的风或湿润效果修改。

`global.weather` 保存天气目标、云量、雨、风、风暴强度、湿润度和风相位。旧 `storm` / `intensity` 继续兼容；旧存档缺少新字段时安全恢复。天气过渡状态与风相位跨世界保留，重新加载后先锚定已有 GameClock 时间，不重复累计已过去的风相位。

## 已执行验证

- `npm run typecheck`：通过。
- `npm run test`：65 个文件、280 项测试通过。新增测试覆盖平滑过渡、雨与雷电分离、旧/新天气存档、风相位恢复、屋顶遮雨、雾距离、质量预算、湿润恢复、室内音频、雷电频率及共享体素资源隔离。
- `npm run build`：通过。
- 浏览器实际渲染 4 种天气 × 清晨 / 正午 / 黄昏 / 夜晚，保存 16 组截图和状态；没有 WebGL / shader 错误。定格控件用于检查最终构图，正常渐变另行检查。
- 密集田地检查使用 648 个可操作单元，其中少量格用于未耕、已耕和收割状态对照。MEDIUM 在本次 786 × 874 检查窗口的最终 16 组样本约 56～57 FPS，CPU 3.7～5.7 ms；这不是所有设备的帧率承诺。
- LOW / MEDIUM / HIGH 均实际切换检查，云 / 星数量与配置预算相符；雨和灯的数量由统一档位配置限制。未进行长时间、多台农机同时驾驶的压力测试。
- 农场屋顶内：`RAIN` 保持，雨幕关闭，室内混音 `rain≈0.01332 / cutoff=1400`。屋外：雨幕恢复，`rain≈0.0666 / cutoff=6500`。小屋入口暖光可见。
- 实际 Home 小屋进入 / 离开：`HOME → COTTAGE → HOME`，室内不下雨、音频衰减，出屋恢复。
- 真实交通船往返：`FARM → HOME → FARM`，完成两次航行；雨强保持约 0.74，湿润度约 0.74，风相位继续推进，农田仍按 GameClock 生长。
- 雨停：目标已是晴天时雨强仍平滑下降；最终雨幕与雨声关闭，湿润度从约 0.74 缓慢降至约 0.36。
- 独立测试端口的真实存档重新加载：去掉天气与时间参数后恢复 FARM、RAIN、HIGH、湿润度和风相位。
- 海边远景检查：海面边界扩展后在远雾内衔接天空，不露出短水面边缘。
- 风暴驾驶：正常上车、前进、停车、下车；犁保持抬起，农田未被修改，发动机声启停正常，第三人称能看到远景。检查窗口驾驶样本约 48～54 FPS，下车后约 57 FPS。

音频节点、资源载入、音量与滤波切换已经检查；扬声器 / 耳机的实际听感及目标设备长期帧率仍需用户验收。

## 检查入口与证据

开发模式：`?world=farm&view=farm-weather&weather=clear&hour=12`，提供天气、四个时段、定格、屋顶内外及真实码头入口。`fixture=1&dense=1` 创建一次性密集农田对照，使用正常农业 API；默认不读取或保存正式游戏进度。需要测试持久化时只在独立端口添加 `persist=1`。正式构建没有这些开发控件。

截图及 JSON 位于 `artifacts/weather/`：

- `weather-matrix.png`：16 组组合对照；各组合原图保留。
- `shelter-quality.json`、`roof-rain.png`、`outdoor-rain.png`：屋顶内外与档位。
- `cottage-transition.json`、`cottage-inside.png`：真实小屋切换。
- `travel-roundtrip.json`、`farm-return.png`：真实跨岛往返。
- `rain-clearing.json`、`save-reload.json`：雨停与存档恢复。
- `ocean-horizon.png`、`storm-driving.png`、`storm-driving.json`：海面与驾驶回归检查。
