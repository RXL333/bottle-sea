# 美术规则

参照附件 2 的横卧瓶体构图、附件 3 的风暴情绪、附件 1/4 的探索尺度。当前没有视频附件。

- 三维体素为主，不使用平面图充当场景；玻璃允许更平滑。
- 水面、地形、树、房屋、珊瑚、船及鱼使用方块；塔使用八面柱。
- 材质 flatShading、有限色板、低成本光照；无外部材质贴图。
- 海洋 #0b6670 / #078a91 / #16b6b4 / #66d4c5；草地 #4c8b35；沙滩 #d8c58a；红白灯塔 #d85849 / #e7e1cf；暖光 #ffca67。
- antialias=false；CSS image-rendering:pixelated；内部像素比不超过 1.25，MEDIUM 使用 0.9。
- 默认瓶体占横屏宽度约六成；房间退到背景，桌面摆件形成尺度参照。
- HUD 使用深色透明底、淡黄绿交互态、等宽字体与中文衬线标题，图标使用简单线条。
- 夜间保持可读性，灯塔扫光和窗户形成暖色焦点；风暴保持同一色板，避免完全黑屏。
- 窄屏自动拉远相机，工具栏缩小；第一人称仍以桌面键鼠为主。

本版本优先明确的体素结构和实时交互，不追求概念图中的电影级光线、真实折射或复杂水下焦散。
