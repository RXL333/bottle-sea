# Bottle Sea 2.0 · Stage 1 视觉与交互精品化

## 范围与当前状态

依据附件 `fb5d52b6-de83-489a-ad16-ed5e36e55411/pasted-text-1.txt`，增量增强同一个 Vite / TypeScript / Three.js 游戏。保留 GameClock、统一 GameLoop、实例化体素海面、共享 WaveMath / Buoyancy、双控制器、Pixel HUD 和开发预览入口。禁止新增平行游戏、物理引擎、后处理链或大型资源。

已阅读 README、全部现有 docs，以及 core / world / systems / controls / ui / utils / styles。起点 commit：6006e84。海水目前使用固定随机色，泡沫未关联波峰；玻璃只有单层 Fresnel；模式切换直接设置相机；尚无观察点、步伐反馈、水面穿越事件和发现卡片。已有天气插值、灯光、鱼泡、程序化音频可直接增强。

## 性能风险与策略

海色和浪峰额外采样、透明泡沫、动态微动画是主要成本。复用 Color/Object3D/向量/TypedArray；泡沫与水花用固定容量实例池；颜色可降低刷新频率。质量仅调密度，不换风格。禁止每帧随机色、动态Mesh创建、实时反射、SSR、SSAO、DOF、Bloom。先优化新增效果，MEDIUM 1080p目标55–60FPS。

### 已修复的阶段回归

- 聚焦后resize不能把特写覆盖为默认全景，OverviewController.fit将home独立维护。
- 切换镜头前清除Orbit阻尼残余，避免控制器交接后再次偏移。
- 波浪不再把累计时间乘以天气强度；风暴通过波能和额外短波连续混合，长期运行后切换天气不会突然推进波相位。船和海面继续共用同一函数。
- 下落进入游泳时保留下落速度并指数衰减，修复跳海停在水面上方、无法产生入水事件的问题。
- 水下退出镜头穿出水面后同步恢复雾和声音，避免回到瓶外最后一帧才突然换色。
- 可选音频解码失败安全fallback；按钮加载期间防止重复初始化；实际素材按自身时长播放。
