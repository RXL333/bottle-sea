# 主角模型与游戏接入

基于用户提供的《瓶中沧海》主角图纸制作原创 Low Poly / Voxel 模型。2026-10-02 已按原图重新调整外观。包含草帽、蓝帽带、分层棕发、面部、米白短袖、背带裤、棕色背包与短靴；采用饱满的头部、收短的躯干、可见脖颈、斜肩袖口与分层碎发，保留原有活动节点和玩法接口。

## 资产

- 可编辑工程：`assets/blender/character/player_character.blend`。独立角色场景，未覆盖已打开的作物工程。
- 游戏模型：`public/models/character/player_character.glb`，脚底原点，Y 向上、Z 向前，原始高度约 1.595m，3,380 三角面。
- 尺寸与节点：`public/models/character/player_character.json`。
- 作者脚本：`scripts/blender/player_character.py` 与外观定义 `scripts/blender/player_appearance.py`，在连接的 Blender 中调用 `build()`，`render_views()` 输出检查图。
- 检查图：`artifacts/character/`，包含 Blender 正面 / 背面 / 头像和游戏内截图。

17 个语义活动节点采用 `userData.part_id` 查找，避免依赖 Blender 为重复对象添加的名称后缀。Hips / Spine / Head / Hat / Backpack，以及左右大腿、小腿、脚、上臂、前臂、手分别可调整。当前采用节点动画，包含待机、步行、跑步、驾驶坐姿；未制作图纸中所有表情或工具作业动画。

## 现有系统衔接

`PlayerCharacter` 属于全局表现层，加载一次；不接管输入、相机、碰撞、农业或玩家数据。行走动画按已有相机实际位移推进；传送、切换场景后重置位移记录。第一人称隐藏头帽和背包，低头可见身体与腿；按当前导航眼高适配室内 / 室外缩放。

进入现有车辆后，使用车辆的 `seatPosition()` 与 `yaw` 对齐髋部，并显示完整坐姿。驾驶员随车辆实时移动和转向；上下车过渡期间暂时隐藏，结束后恢复相应姿态。仅对已驾驶车辆的玻璃克隆材质并降低不透明度，使驾驶员可见，不修改共享建筑材质或车辆碰撞。

菜单、睡眠、旅行等过场隐藏角色。世界卸载不释放全局角色；角色释放时统一释放自己的几何与材质，失败或取消加载也释放已加载资源。材质按活动节点合并成共享顶点色材质，保留色板并降低绘制次数；低质量关闭角色投影。

无需新增存档字段：已有玩家位置、世界和车辆状态仍为唯一状态来源。没有保存 Three.js 对象，也没有修改库存、作物成长、车辆操作或物品转移规则。

## 开发验证

仅开发环境可使用：

- `/?world=farm&view=farm-character&hour=10`：模型查看与靠近两种农机，随后通过实际 E 交互上下车。
- `/?world=farm&view=farm-character-body&hour=10`：第一人称低头检查。

默认开发预览使用独立默认状态且不保存，不覆盖玩家正常游戏进度。生产构建不提供这些预览入口。

本次验证：独立 typecheck 通过；58 个测试文件、261 项测试通过；生产 build 通过。新增 5 项真实 GLB 测试覆盖比例 / 原点 / 活动节点、材质批处理、第一人称隐藏与室内缩放、位移姿态、两种农机转向和移动时的坐姿对齐、共享玻璃保护、加载取消与资源释放。

浏览器实测包含模型显示、行走 / 跑步姿态切换、背包背面、拖拉机上车与短促前进 / 刹车 / 下车、收割机上下车、第一人称身体检查。运行检查未发现控制台错误。完整长时间游玩、全部地图路线和最终外观审美仍待用户验收。

## 2026-10-02 外观修订

按同一张图纸重新制作头脸、碎发、草帽层次、领口、棕色肩带、圆铜扣、裤腿、卷边、短靴与背包。修复下巴与衣领重叠导致脖颈被遮挡的问题，额外输出 `character-side.png` 检查侧面轮廓。

模型维持约 1.595 米、脚底原点和 17 个原有语义节点，3,380 三角面。游戏运行时代码、操作、碰撞和动画算法均未修改。资产直接替换原 GLB 路径；Blender 文件保持可编辑。

验证：280 项全量测试通过；最终脖颈修订后 5 项真实角色 GLB 集成测试再次通过；正面、背面、侧面和头像渲染检查完成。未在本轮重新进行浏览器驾驶操作，驾驶位置及姿态兼容由现有集成测试验证。
