# 农业视觉、声音与反馈

本阶段保留农业规则、背包转移、生长时间及存档格式。画面读取 FarmSystem / CropSystem；农机继续使用现有成功作业计数。

## 画面

| 状态 | 表现 |
| --- | --- |
| 未耕地 | 浅色硬土、少量土块 |
| 已耕地 | 深色底土、连续垄沟 |
| 已播种 | 暖色垄沟、种穴及 Registry 的 Seed 模型 |
| 生长中 | 深色土壤、实际 Sprout / Growing 阶段模型 |
| 成熟 | 实际 Mature 模型及成熟状态标记 |
| 已收割 | 浅灰褐土壤、短残茬 |

小麦、玉米、土豆继续使用已有的 12 个 GLB 阶段模型。作物通过材质批次实例化，阶段只在农业修订号或全局生长截止时间变化时重建实例矩阵。幼苗、生长和成熟植株在 GPU 中轻微摇摆，匹配的深度材质保持阴影一致；摇摆不修改模型源资源、碰撞或作物数据。

步行进入主农田时，左侧“农田手记”显示六状态图例，以及脚下农田、单元坐标、作物及阶段。右侧继续使用现有 E 提示；驾驶继续使用原农机状态面板和 J / K / L 操作。

## 操作效果与声音

- 仅成功状态变化产生土块、播种落粒或收割碎屑。重复耕地、种子不足、未成熟作物、背包或粮仓容量不足均不显示成功效果。
- 初次加载、重入农场和存档恢复建立表现基线，不重播历史操作。作物自然成长只更换阶段模型。
- 干燥的农田、土路和农机区内，行驶农机有少量扬尘；停车、离开土面、距离过远或强风暴时不产生新扬尘。已有粒子在短暂生命周期结束后消失。
- 沿用原“声音”开关和 AudioContext。发动机声音随速度与距离变化；占用并停稳时保持轻微怠速，下车或离场后淡出。
- 农具落下、车辆移动且真实作业计数增加时，产生对应作业声；抬起、关闭、停车、种子不足或满仓后停止。每次附近的真实成功操作还会产生短促声音。
- 声音采用程序生成的发动机与过滤噪声，不增加外部声音资源请求。音色、音量舒适度仍需要玩家试听验收。

## 质量与预算

| 项目 | LOW | MEDIUM | HIGH |
| --- | --- | --- | --- |
| 粒子上限 | 0 | 128 | 256 |
| 每帧作业事件预算 | 0 | 8 | 12 |
| 事件粒子数 | 0 | 6 | 10 |
| 效果距离 | 18m | 24m | 38m |
| 作物风摆 | 关闭 | 轻微 | 轻微 |
| 作物投影 | 关闭 | 关闭 | 开启 |

LOW 始终保留土地、作物模型和交互信息，作业声音仍然可用。所有粒子共用一个固定池和一个 InstancedMesh，最多处理四台机器的扬尘；音频最多两台附近农机、12 个固定节点、6 个同时存在的短音效（18 个临时节点）。原有环境声另计。

## 验证记录（2026-10-01）

- `npm run typecheck`：通过。
- `npm test`：52 个测试文件、223 项通过。新增覆盖真实状态成功/失败事件、重入基线、原农业状态不被表现修改、12 个真实 GLB、批次合并、实例矩阵稳定、粒子坐标/容量/寿命/地面限制、音频作业状态/距离/节点上限/清理。
- `npm run build`：通过。
- 隔离浏览器中验证 648 单元、639 株作物；HIGH / LOW / MEDIUM 的状态和模型数量一致，作物与土地共 54 个可见批次。当前设备、1280×720 场景的 HUD 采样约 56 FPS；这是本机场景观察值，不代表其他硬件的保证。
- 实际驾驶犁地机：35 个新耕地单元，保护的生长作物保留；触发耕地短音效及粒子，离开主田、停车后无作业声音。
- 实际驾驶播种机：消耗 8 份小麦种子、播种 8 个单元；种子耗尽后作业自动停止，作业声音停止，移动扬尘仍与车速和地面一致。
- 实际驾驶收割机：作业中 29 个活动粒子、一个发动机声部及一个作业声部；粮仓最终 60 / 60，收割 20 格。容量不足后停止作业声和新收割效果，未成熟及不支持作物保留。
- 密集场景存档重新加载：639 株作物恢复，历史作业效果计数为 0。
- 脚下单元手工耕地后，图例坐标和提示从未耕地切换为已耕地；缺少种子的失败操作未追加粒子或短音效，LOW 的作物状态仍正确。
- 浏览器捕获未发现 WebGL / JavaScript 警告或错误。主观音色、摇摆幅度和操作舒适度待玩家验收。
