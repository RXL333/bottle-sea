# 基础经济与交易

主岛和农场码头都有独立商船。步行靠近按 **E** 打开交易面板；交通船继续负责旅行。面板打开时暂停游戏操作与时间，关闭后恢复原有步行控制。

## 首版商品

- 初始金币 **100**。出售随身背包中的鱼、三种作物、四种料理、鸡蛋、牛奶和羊毛。
- 购买小麦种子、玉米种子、土豆种薯和通用牧场饲料。物品进入统一 Inventory；牧场饲料由原 LivestockSystem 使用。
- 农机商品先开放 **一台增购联合收割机，800 金币，限购一次**。在农场商船购买后交付农机棚外划线停放位。复用现有 GLB、驾驶、收割、向拖车 / 谷仓卸粮和存档。原有拖拉机、收割机和农具保留。当前不出售其他农机。
- 谷仓两级升级：**24 → 36 → 48 格**，费用 180 / 360 金币。
- 所有联合收割机车载粮仓两级升级：**60 → 90 → 120 份**，费用 220 / 440 金币。原有货物保留，当前车辆立即扩容。
- 商品与价格集中在 `src/gameplay/economy/TradeCatalog.ts`；名称、分类、图标、堆叠规则继续来自 ItemRegistry。第一版为固定价格。

## 数据和事务

`EconomySystem` 校验数量、余额、背包物品与接收容量、升级顺序和购车交付条件。有效交易同步提交资源后请求存档。背包满、钱不足、物品不足、重复购车、停放位被障碍物 / 车辆 / 动物 / 玩家占用时拒绝交易；交付或资源提交异常时回滚。保存的递增请求序号拒绝同一请求重放。

购车使用独立车辆 ID `farm.combine.purchased`。交付时检查实际车辆碰撞体、地形和指定停车区域。新增车辆同步加入其他车辆的碰撞与镜头遮挡列表。与原有车辆共用 FarmTransportSystem；不另建农业生产规则。

SaveSystem 继续使用既有 v2 存档，新增 economy 字段保存金币、交易序号、购买记录和升级等级。先恢复升级容量，再恢复谷仓 / 车辆粮仓，避免扩容后的物品被截断。旧存档没有经济字段时使用 100 金币和零级升级，不回收已有物品或车辆。速度、输入、乘坐状态和模型仍不写入存档。
