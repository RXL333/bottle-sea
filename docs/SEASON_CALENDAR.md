# Season / Calendar

## 日历与存档

每季 28 天，一年 112 天，七天一周。第 1 天为第 1 年春 1 日星期一；原有默认时间仍是春 8 日，旧玩家的累计天数不会重置。`CalendarSystem.date` 直接从 `GameClock.simulationTime / DAY_DURATION` 推导，所有世界和小屋使用同一服务。

Calendar 不累计 delta，不使用 Timer。睡觉与旅行仍通过原 `GameplayTime / GameClock` API 推进。展示权重在约数十秒内渐变，暂停日期不会阻止已触发的换季渐变完成；不修改物理阴影投影或生成四套地图。

Save v2 原 key 保持不变，增加 `calendar.version / lastAnnouncedSeasonIndex` 通知游标。日期/年份/星期/季节不存第二份权威数据，加载时从已恢复的 GameClock 推导；缺少或非法 Calendar 字段使用当前时间默认值。保存后不会重复弹出同一次换季通知。

全局 Weather 增加 `scheduledDay` 和渐变中的 `snow`。每日目标天气按日期与季节权重确定；大跨度快进直接取目的日，不逐日模拟。手动天气在当天保留到次日；旧天气存档缺少调度字段时，保留其当前天气到次日。雨雪仍使用已有降水实例数、风相位、音效与质量设置。

## 四季表现

| 季节 | 天气倾向和环境 | 光照白昼 | 新播种/种子供应 |
| --- | --- | --- | --- |
| 春 | 嫩绿、柔和蓝天、晨雾、较轻细雨；雨天权重 40% | 06:00–18:00 | 小麦、玉米、土豆 |
| 夏 | 浓绿、清透蓝天、暖光白云；晴天权重 65%，偶有雷雨 | 05:00–19:00 | 玉米 |
| 秋 | 金棕草木、柔和海天、增强凉爽海风 | 06:30–17:30 | 小麦、土豆 |
| 冬 | 霜色草木、冷蓝海天、阴天较多；原雨天表现为轻雪、风暴表现为风雪，降水声音较柔和 | 07:00–17:00 | 当前三种作物休耕；饲料、出售、农机与升级正常 |

冬季霜色和雪是风格化表现，没有温度、积雪碰撞、受灾、枯萎、死亡或生存伤害。雪仍受屋顶/小屋屏蔽，风雨音效仍受室内混音影响。春/秋普通雨强度较轻；风暴仍沿用现有可游玩强度。

`SeasonalEnvironment` 仅在世界加载时注册地形与树木材质；使用少量 uniform 着色，不逐帧遍历/重建土地。保留原风摆 shader、湿润材质和阴影投影；颜色遮罩仅影响绿色植被，不用换季颜色覆盖作物的真实阶段。Farm 的农田和作物状态表现不变。

## 生产联动

- CropRegistry 是适种季节的唯一作物配置源。FarmSystem 在种子/土地事务前检查当前季节；手工和播种机共用。已有作物不受新播种限制，离岛、睡觉、跨季后仍按播种时间成熟。
- 播种机非适种时停止作业，选择按钮标明“非适种季”，作业提示说明适种季节；不扣种子、不覆盖原作物。
- Fish 的季节权重保存在 ItemRegistry 的 `fishing.seasonWeights`。春季小鱼更多、夏季金枪鱼/红鲷鱼权重提高、秋季鲭鱼更多，冬季红鲷鱼暂不出现，其余五种可钓。挂钩鱼和暂存鱼保留，原张力玩法不变。
- TradeCatalog 种子供应从 CropRegistry 读取，非种子商品可用 `allowedSeasons` 扩展。报价与交易提交执行相同季节检查，失败无扣款/发放。价格固定，出售不受季节限制。

## 界面与扩展

点击右上日期或按 **L** 打开海岛日历：日期、星期、累计天数、当前季节、28 格月历、近期七天参考天气、适种作物及当季鱼讯。复用 `ui-panel / UIChrome`，内部滚动与窄屏布局保持海岛视觉语言。

新季节配置集中在 `src/gameplay/calendar/SeasonRegistry.ts`，不可在农业/钓鱼/商店里重复维护季节名称或作物适种表。天气预报是确定性的每日参考，当前手动天气可与其不同。未来节日/订单等只应读取该日历，不新增时间源。

DEV 验证入口：`?world=farm&view=season-calendar&fixture=1&persist=1`。`day` 是累计天数，`hour` 设置当日时间；不用 `persist=1` 时不会改写普通存档。测试应使用独立 localhost 端口。季节验证按钮推进原 GameClock API；无季节旧存档按钮仅作用于显式 DEV 副本。生产构建不包含这些入口控件。

验证记录见 `docs/SEASON_CALENDAR_VALIDATION.md`，截图见 `artifacts/season-calendar/`。
