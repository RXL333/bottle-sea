## 验证边界

- 浏览器通道提供 viewport 调整，没有真实浏览器缩放设置接口；800×450 是缩放等效空间检查，未宣称操作过浏览器 200% 缩放。
- 浏览器本轮检查的是 UI、必要状态及输入恢复，没有重跑完整钓鱼获鱼、全部配方、所有农机作业、畜牧生产、经济交易和存档端到端流程；这些既有系统的自动测试已随完整测试集运行。
- 原浏览器锁定后的连续面板恢复由控制器回归测试验证；浏览器实测确认关闭面板后车辆能够重新移动。未将自动化的未锁定输入操作当成所有浏览器锁定手势的验证。
- DEV 预览的「开发验证」折叠控件属于检查工具，不出现在正常游戏页面。
- 没有增加参考图中的新地图 / 小地图功能。原有功能和快捷键继续复用现有模块。
