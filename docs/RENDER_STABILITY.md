# 表面与阴影稳定性修复（2026-10-08）

## 原因与处理

- Three.js 0.186 的 PCF 阴影按屏幕像素随机旋转采样。镜头移动时，采样噪声跟着屏幕改变，容易在低多边形表面爬动。`StableShadows` 在材质编译前固定采样方向，保留 PCF 软阴影；测试检查当前 Three shader 结构，升级 Three 时必须复核。
- 主岛与农场使用不同大小的阴影投影，现在分别设置法线偏移和深度偏移，消除掠射角自阴影条纹。投影继续固定在世界空间，昼夜改变光色和强度。
- GLB 中有装饰面、木边和石基共面。`separateModelSurfaces` 在资源加载时检查同一父节点内重叠的同向平面，将后层表面轻微外移。保留节点、材质、UV、法线和三角形数量；不跨越独立门、轮子、肢体，不处理骨骼或 morph 网格。不添加逐帧修复开销。
- 表面分离可能产生 indexed / non-indexed 混合几何。农场和主角合批仅在混合批次中统一索引形式，保留原有批次数与动画节点。
- 低处钓鱼台保留局部地形下沉。商船平台恢复原始草地高度，甲板顶面提高到 3.94（比相邻草地高 0.02），避免整块地形下沉造成岸边大空隙。
- 用户再次反馈的商船平台四角黑块来自程序化支柱与木板顶面共面，早期 GLB 修复未覆盖这处程序化模型。支柱顶面收进木板内部，保持实际接触；商船老板、地面高度和碰撞同步调整。
- 渔夫进一步移至小屋旁的小棕榈树附近 `[-2.53, 3.74, -0.22]`，保持 NPC ID、对话和委托数据不变，避开钓鱼入口。钓鱼通道和交互焦点加入回归检查。

原始 Blender / GLB 文件未修改，修复在加载后的运行时几何上完成。农业、物品、车辆控制及存档格式未修改。
