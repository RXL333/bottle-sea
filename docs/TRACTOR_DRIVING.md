# 第三人称与拖拉机基础驾驶

拖拉机位于 FarmWorld 农机停放区（原有红色拖拉机，地图坐标 -20.5 / 2）。靠近后按 E 上车；0.8 秒镜头过渡结束后开始驾驶。

| 按键 | 操作 |
| --- | --- |
| W / S | 前进 / 后退；行驶中按反方向先减速 |
| A / D | 左 / 右转向；倒车时方向符合车辆转向 |
| Space | 刹车 |
| E | 停稳后安全下车，恢复第一人称 |
| H | 停稳并对准农具连接点后挂接 / 分离 |
| J | 作业农具抬起 / 落下；犁耕地、播种机播种 |
| K | 已挂播种机切换作物种子（也可使用驾驶 HUD 按钮） |
| Esc | 释放鼠标并停车；双击画面可重新锁定 |

松开油门会惯性滑行并减速。切换浏览器窗口、隐藏页面或失去鼠标锁定会清除输入并停车。上下车保留已有鼠标锁定；浏览器拒绝锁定时仍可用键盘驾驶。

## 模块与边界

- `VehicleMotion` 使用真实帧间隔、最高 120 Hz 子步长、低速转向和随速度降低的转向幅度。它与 GameClock、土地及作物状态无关。
- `VehicleController` 接管键盘和共享镜头；ExploreController 在车上暂停，下车恢复。沿用 InteractionSystem 的 E 入口。
- `VehicleFollowCamera` 平滑位置、朝向与旋转，障碍物遮挡时立即缩短镜头距离，离开遮挡后平滑恢复。视线支点设在车顶以上，防止收缩进驾驶室。
- `TractorVehicle` 使用现有模型层级，前轮转向与轮胎滚动分别作用于两层轴点。内外轮角度和滚动距离按转弯半径区分。
- `VehicleNavigation` 由世界提供几何查询。FarmVehicleNavigation 对旋转车身执行 SAT 碰撞检查，使用现有地图障碍、交通船与地形数据；码头及岛外不可驶入。镜头对 GLB 几何发射带余量的射线，地形使用共享高度查询，避免逐帧扫描整岛体素。
- 下车候选优先在车体两侧，其次前后；检查玩家体积、落脚土地、静态和动态碰撞以及镜头过渡路径。没有安全位置时提示先移动车辆。
- 移除了拖拉机原位置的静态碰撞体，步行碰撞使用它当前的动态车身。

## 模型与后续挂点

`tractor.glb` / `tractor.blend` 保留原有几何与四个轮轴，新增语义节点 `Body`、`Seat`、`Hitch_Back`。生成脚本和资源清单同步更新。

`hitchBackTransform()` 返回后挂点世界变换矩阵；现已通过独立 HitchSystem 接入前后挂点与犁、播种机、拖车的挂接/分离。参见 [农具挂接说明](IMPLEMENT_HITCHING.md)、[挂犁耕地说明](TRACTOR_PLOWING.md) 与 [播种机说明](TRACTOR_SEEDING.md)。农业作业复用共享 FarmSystem；拖车仍只支持挂接，不运输货物。

## 存档

现有 v2 存档增加独立 `vehicles` 字段，仅白名单保存车辆 ID、世界、x / z 和 yaw。缺字段的旧存档默认停在原农机区；无效数据或落在障碍物、码头、岛外的位置使用默认停放位置。

车辆位置实时写入内存状态；上下车、失焦、页面离开及现有存档入口保存。刷新和再次旅行返回 FarmWorld 会恢复停放位置；玩家以原有步行出生点进入，车辆速度、输入和乘坐状态不持久化。

## 交付检查

基础驾驶交付时按用户分工仅做静态检查。2026-10-01 挂接阶段按新的要求执行 typecheck、test（170 项通过）、build，并实际进入游戏验证上车、挂接、前进/转向/倒车、碰撞停止、分离、下车和刷新恢复。具体覆盖范围见农具挂接说明。
