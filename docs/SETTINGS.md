# 游戏设置与驾驶优化

入口：画面右上角“设置”，快捷键 O；O / Esc 或关闭按钮返回。

## 可调整项目

- 车辆转向：鼠标 + A/D、仅 A/D、仅鼠标。所有方式保留 W/S、Space 和农具按键。
- 鼠标转向灵敏度：0.25–2 倍。新的默认系数为每像素 0.0025，原为 0.008，默认转向幅度降低 68.75%。
- 左键拖动观察灵敏度、第三人称跟随距离；松开左键平滑回到跟随镜头。
- LOW / MEDIUM / HIGH、50%–125% 相对渲染精度、帧率显示。
- 步行视角灵敏度、纵轴反转、钓鱼长按 / 点击。
- 游戏声音开关、总音量、恢复默认。

## 状态与模块

`SettingsState` 只保存偏好，SaveData.settings 负责持久化和校验。旧存档缺少设置时使用默认值，农业、车辆、物品等状态继续使用原系统。

画质保留原 global.quality，钓鱼方式保留原 FishingSnapshot.inputMode。设置界面直接调用这两个现有所有者，不维护第二份状态。

打开设置会停稳车辆、暂停驾驶及农具输入，并通过现有面板暂停路径冻结游戏时间。关闭清空旧按键，再恢复原控制。已有鼠标锁定会尝试恢复；浏览器拒绝锁定时仍可使用原有未锁定输入。

保存的声音偏好在下一次真实键盘 / 鼠标操作时启动 WebAudio，以满足浏览器自动播放要求。恢复默认不会删除游戏进度。

## 性能

FarmModels 保留未渲染的静态来源分组用于镜头查询，实际渲染仍使用原有材质合批。镜头首先检查每个建筑、树木的包围盒，只有射线附近模型参与精确几何检查；移动资产更新范围，驾驶车辆排除自身，五条射线继续保护近裁面。

跟随镜头每帧仅对最终插值位置做一次碰撞检查，避免重复全场射线；复用临时向量、减少车座读取时的整车矩阵更新。较重的 DEV 存档诊断序列化只在已有验证场景或 `?debug=1` 中启用。
