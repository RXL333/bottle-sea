# FarmWorld 正式地图基础

农场从 26×20 原型岛扩展为约 72×76 的独立岛体，南侧保留原客运码头，南部为生活/仓储/农机中心，中部为三块主田，北部为农业扩展及畜牧预留。使用仓库已有 GLB，保持体素地形、低多边形资产和低密度环境装饰。当前不实现种植、成长、驾驶、动物 AI 或经济。

所有尺寸均为项目世界单位，不直接等同于现实米。HomeWorld / TravelWorld / WorldManager 的生命周期、旅行流程、玩法状态和存档格式保持原接口。

## 农机空间预算

农机统一缩放 0.5，从 `public/models/farm/manifest.json` 的 Blender bounds 换算完整 X/Z 包围盒，包含收割机侧向突出部件及拖车牵引杆。

| 资产 | 宽 | 长 |
| --- | --- | --- |
| 拖拉机 | 1.11 | 1.65 |
| 播种机 | 1.61 | 1.50 |
| 收割机 | 2.26 | 2.24 |
| 拖车 | 1.03 | 1.93 |
| 犁 | 1.51 | 0.66 |

- 主路与田间支路宽 5：比最宽收割机多约 2.74 的横向余量。
- 主田左右间隔 10，分别设置 X=-11 / 11 的道路；南北横路位于 Z=-5 / -33，北部预留区横路位于 Z=-39。
- 每块主田的南北田头各深 10，内含 10×10 的掉头空地；不以围栏或台阶封闭田块入口。
- 拖拉机与拖车按当前包围盒加 0.3 牵引间距，车组长度预算约 3.88。未来 Vehicle System 须将车组外侧扫掠半径控制在 5 以内，并在此地图上验证转弯与机具展开；当前没有驾驶物理，不声称已验证实际驾驶。
- 机棚按 1.0 建筑比例设置，其门柱内侧开口约 4.2，静态收割机的完整宽度约 2.26。收割机前置割台可探出机棚，后部避开工作台。
- 客运栈桥仍为步行上下船通道，并非车辆渡轮；主路从岸上连接码头。

## 稳定的地图接口

`src/worlds/farm/FarmMap.ts` 导出 `FARM_MAP`（version=1）、`FARM_FIELDS`、`FARM_ZONES`、`FARM_ROADS`、`FARM_TURNING_AREAS`、`FARM_VEHICLE_ENVELOPES`、导航边界、码头/船位常量。`FarmWorld.map` 引用同一份空间定义。

三块主田 id 固定为 `field-west`、`field-central`、`field-east`。每块 `grid` 为 12 列 × 18 行、cellSize=1，分别预留 216 格，共 648 格。原点在最小 X/Z 角，列向 +X、行向 +Z；纯函数 `farmFieldCell(field,x,z)` 与 `farmCellCenter(field,column,row)` 提供坐标映射，半开边界外或非法索引返回 null。这里只定义空间，没有建立农业运行数据或写入存档。

扩田、鸡舍、牛棚、羊圈和牧场有各自稳定 zone id 与 reserved=true。未来系统根据这些区域规划实体，使用当前世界导航高度，不将预留区误当作已建建筑或已种田块。

`FarmTopography` 的同一单位网格同时决定可见体素顶面、模型基础和导航地面。主田与道路位于平坦平台，坡地只在岛缘。码头、房屋台阶、门廊与机棚基础另有可行走表面；建筑、车辆、树干、围栏和路牌有静态碰撞。FarmOcean 独立覆盖所有岛岸，复用共享 WaveMath；TravelOcean 不修改。

环境按材质全局合批。车辆和动物保留独立 Group 与 placement id，并在语义节点内合并几何；轮子、牵引点、头部等节点的层级和枢轴保留，以便未来系统接管。当前动物不播放行为或头部动画，只有环境风车转动。

## 旅行与旧存档

继续使用 `FARM`、`farm_dock_arrival`、到达点 `[-4,4.44,14.5]`、船位 `[-2.55,3.3,14.5]` 和 `farm_boat / TRAVEL`。返回 HomeWorld 的目的地面板、行程和存档链路沿用现有实现。地图没有新增生产状态、物品或 SaveSystem 字段，不要求清档。

Game 仅针对 FARM 扩大阴影覆盖、调整远景雾密度，并让局部雨/天空随探索位置移动；进入其他世界时继续恢复原环境参数。

## 用户待验收

实现仅经过 TypeScript strict 和变更检查；未运行自动测试、生产构建、浏览器或游玩验收。已有测试中的旧地图坐标和范围断言已随布局更新，等待用户运行。

推荐路径：码头下船 → 农场中心 → 西/中/东主田及田头 → 西侧农机棚/停车区 → 北侧畜舍预留 → 牧场西侧开放入口 → 原码头 → 返回家园岛。再核对房屋门廊、建筑/车辆碰撞、岛缘坡地、夜间/风暴、画质切换及重复往返。

开发入口默认隔离存档，`npm run dev` 后可使用：

- `/?world=farm&hour=12`：原到达点步行。
- `/?world=farm&view=farm-overview&hour=12`：全岛布局。
- `/?world=farm&view=farm-fields&hour=12`：三块主田。
- `/?world=farm&view=farm-yard&hour=12`：农机棚与停车区。
- `/?world=farm&view=farm-cottage&hour=12`：小屋门廊。
- `/?world=farm&view=farm-expansion&hour=12`：扩田预留。
- `/?world=farm&view=farm-livestock&hour=12`：畜舍预留。
- `/?world=farm&view=farm-pasture&hour=12`：牧场入口。
